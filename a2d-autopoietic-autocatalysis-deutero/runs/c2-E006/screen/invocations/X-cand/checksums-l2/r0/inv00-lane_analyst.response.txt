1. **R1–R2, R19, R30:** Preserve every free function and exact public type, field, variant, and method signature. `Stream` fields stay private; it requires `Debug, Clone`. `Span`, `Hashes`, and both error enums require all five listed traits. Follow the single-file, edition-2024, std-only and output-format restrictions.

2. **R3–R7, R16:** CRC uses reflected IEEE processing with the specified initial/final XORs; Adler updates `b` using the newly updated `a`. Process every unsigned binary byte, including NUL and values ≥128. Results are numeric, independent of endianness; empty results are CRC 0 and Adler 1.

3. **R6, R18, R30:** Adler arithmetic must remain exact for arbitrarily long inputs in both standalone and streaming paths. Avoid overflow before reduction. Processing must be linear in selected bytes plus spans, with bounded auxiliary space and no concatenated buffer or retained input copies.

4. **R9–R12, R17:** Validate each span completely in supplied order: reversed, start bounds, end bounds, then overlap. The earliest failing span wins over every later error; within that span, the stated precedence wins. Report zero-based indices and actual offending endpoints, and never panic—even for `usize::MAX` endpoints.

5. **R8, R11–R12, R14:** Ranges are end-exclusive; endpoints equal to `data.len()` and adjacency are valid. Compare each start against the immediately preceding end. Never sort, coalesce, or infer validity from equal byte contents.

6. **R13–R15:** Empty spans still undergo bounds and ordering checks and become the boundary for the next span. An empty span inside its predecessor overlaps; one in a gap advances the boundary. Repeated empties at one position are valid. Only valid empty-only collections yield the empty checksums.

7. **R8, R15–R16, R24:** Hash selected bytes as one concatenation, skipping gaps and initializing once. Successful `update_spans` appends that concatenation to existing state. No spans or valid empty-only spans produce empty checksums in the free function and preserve an existing stream.

8. **R21–R23, R29:** Seeds are finalized numeric checksums: undo only CRC’s final XOR and unpack Adler directly, without adding 1. Every CRC value and Adler zero are valid. Each Adler component must be strictly below 65521; invalid `a` wins over invalid `b`.

9. **R20, R23, R25, R29:** Checksums and snapshots are repeatable, nonmutating reads. Every chunking must agree, including empty updates preserving arbitrary valid seeds exactly. Reset always restores standard empty state; clones evolve independently.

10. **R17, R24:** A failed `update_spans` must leave both components unchanged even after earlier valid, nonempty spans. The visible error test fails immediately and therefore does not establish rollback correctness.

11. **R26–R27:** Snapshot format is exactly 19 ASCII bytes: `c`, eight lowercase zero-padded finalized CRC digits, `:a`, then eight packed Adler digits. Restore checks byte length and markers at offsets 0, 9, 10 before any digit or seed validation.

12. **R28–R29:** After shape passes, inspect digit bytes at offsets 1–8, then 11–18, accepting only ASCII `0-9a-f`. Report the first invalid byte offset, including for UTF-8 input; uppercase is invalid. Validate all digits before Adler validity, then apply the same `a`-before-`b` seed checks.
