1. **R1–R2, R18, R27:** Deliver one Rust source file in `rust` fences, compiling under edition 2024 with std only and no inner attributes/doc comments. Preserve all three exact public signatures; accumulate every specified variant in one public `PathError`. Both types require the specified derives; `Link` fields are public `String`s.

2. **R3–R8, R21:** Validate the entire raw input before traversal: Empty → first NUL anywhere → first backslash anywhere → first forbidden ASCII control anywhere. This is category precedence, not earliest offending byte across categories. Offsets are original UTF-8 byte offsets. Preserve spaces, Unicode, percent escapes, case, and other allowed characters literally.

3. **R9–R14:** Only an initial slash makes a path absolute; every slash run collapses, including leading runs. Only exact `.` and `..` components are special. Parents cancel ordinary components, never retained parents. Relative parents accumulate without an arbitrary cap; absolute underflow returns the earliest offending parent’s offset. Empty reductions become `/` or `.` respectively.

4. **R15–R17:** Compute directory intent from the raw spelling: final slash or last nonempty component exactly `.`/`..`. Append one slash only when reduced components remain, including retained parents. Thus `..` → `../`, `a/..` → `.`, and `a/.` → `a/`. Successful normalization must be idempotent and independent of filesystem/environment.

5. **R18–R21, R26, R28:** Validation order is cwd → supplied home → link table, when applicable → requested path. Validate contexts even for absolute requests or unused home. Each must start with `/` and normalize successfully; hide all underlying failures behind InvalidCwd/InvalidHome. Context normalization is lexical, rejects root escape, and never expands tilde.

6. **R22–R25:** After request lexical validation, only initial `~` or `~/` expands home; absent home yields MissingHome. Any other byte after initial `~` yields UnsupportedTilde `{ at: 1 }`, even without home. Other tildes stay literal. Consume the tilde and at most one following slash; ignore remaining repeated slashes.

7. **R19–R26:** `resolve` starts from root, normalized cwd, or normalized home as appropriate, treating context components as a directory regardless of trailing slash. Return an absolute result; request parents can escape that starting directory but cannot escape root. Escape offsets include any original tilde prefix. Final directory intent comes solely from the request: bare `~` has none.

8. **R28–R30:** Validate links in slice order without sorting. Keys must equal their successful normalization exactly, be absolute, non-root, and lack a trailing slash. Targets need only pass raw lexical validation: relative, noncanonical, cyclic, and root-escaping targets are allowed. Validate both fields before duplicate detection; report the earliest entry error and the original first duplicate index.

9. **R31–R32:** In `resolve_links`, traverse normalized cwd/home components from root before request components; absolute requests skip those components. Context component offsets are zero. Every pushed ordinary component triggers immediate exact full-path lookup, including context and target components. Expand before any following `.` or `..`; neither special component triggers lookup itself.

10. **R33–R34, R37:** Relative targets replace the matched link name starting at its parent; absolute targets reset to root. Traverse raw target components fully before resuming suspended components. Target tildes are literal, target Escape offsets are local byte offsets, and resumed request offsets remain original. Never pre-normalize targets or borrow their directory intent.

11. **R35–R36:** Keep a matched link active until its entire target and nested expansions finish, then deactivate it before resuming subsequent components. Reentry while active returns Loop; a completed link may expand again. Check active membership before budget, so Loop beats Limit even when the budget is exhausted.

12. **R13, R17, R27, R36–R37:** Budget counts every actual expansion across contexts, targets, and request, including repeated completed expansions. Test `count >= max_expansions` before incrementing; `usize::MAX` must not overflow. Zero permits paths encountering no links. Reset budget/active state per call, impose no extra parent/depth cap, perform no I/O, and leave earlier APIs unaffected by links.
