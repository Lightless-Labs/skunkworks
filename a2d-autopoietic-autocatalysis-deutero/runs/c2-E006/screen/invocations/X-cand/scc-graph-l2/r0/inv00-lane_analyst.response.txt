1. **R1–R2:** Deliver one Rust source file in `rust` fences, compiling with edition 2024 and std only; no inner attributes/docs. Preserve every public name, field, type, variant and derive exactly; keep helpers private.

2. **R4–R7:** Validation precedence is vertex limit → edge limit → endpoints. Oversized `n` wins over every other error; excessive edge count wins over invalid endpoints. Both limits are inclusive, and duplicates/self-loops count toward the edge limit.

3. **R6–R7:** Scan the original slice in order, checking source before target for each edge. Return the earliest failing edge, preferring its source if both endpoints fail; preserve the original index and offending value, including `usize::MAX`. Compare before indexing or arithmetic that could overflow.

4. **R3, R15–R16:** With `n = 0`, empty input succeeds with all five vectors empty; nonempty input within the edge limit fails at source index 0. With positive `n` and no edges, emit ascending singleton components, identity mapping, false flags, zero internal counts and no arcs.

5. **R8–R10, R14:** Compute maximal **directed** strongly connected components, including isolated vertices. Zero-length reachability includes each vertex itself; one-way connectivity does not merge vertices. Each component contains distinct members sorted ascending.

6. **R11–R12:** Sort components by size descending, then smallest member ascending. Assign IDs only from that final order and remap every component-indexed field and arc endpoint accordingly; IDs are neither vertex minima nor traversal numbers.

7. **R13–R14:** A component is cyclic exactly when it has multiple vertices or a singleton self-loop. Incoming/outgoing edges alone do not make a singleton cyclic; repeated edges cannot independently create cyclicity.

8. **R3, R17–R18:** Results must be owned and independent of prior calls. Edge permutations must preserve components, their IDs and cyclic flags. Support every valid input through both maxima without panics, including long paths, disconnected graphs and one all-vertex SCC.

9. **R19–R20, R26:** `internal_edges` has one count per canonical component and counts original occurrences, including every duplicate and self-loop. An acyclic singleton necessarily has count zero.

10. **R21–R23:** Emit exactly one arc per distinct **ordered component pair**, aggregating even different vertex pairs between those components. Its multiplicity counts every original occurrence; internal edges never produce arcs.

11. **R24, R26:** `first_edge` is the minimum original slice index represented by that arc. Internal edges, self-loops and duplicates still occupy positions; never derive witnesses from filtered or deduplicated lists.

12. **R25–R26:** Sort arcs by source ID ascending, then target ID **descending**, with no multiplicity/witness tie-breaker. Every original edge contributes exactly once to either an internal count or an arc multiplicity; their total must equal the input length.
