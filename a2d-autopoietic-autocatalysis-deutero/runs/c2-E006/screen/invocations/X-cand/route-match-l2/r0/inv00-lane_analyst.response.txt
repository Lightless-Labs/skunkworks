1. **R1–R2:** Deliver one std-only Rust 2024 source file inside `rust` fences, with no inner attributes or inner documentation. Preserve the exact public API, required derives, and private Router fields; additional helpers must be private.

2. **R3, R17, R19:** IDs count successful additions only, starting at zero. A failed add must leave all state unchanged. Repeated identical or equivalent patterns get distinct IDs; ties favor the earliest successful registration.

3. **R4–R5:** For resolve, remove the suffix beginning at the first raw `?` or `#` before any validation. Ignore even malformed or non-ASCII suffixes. The remaining head must start with `/`; an empty head fails at 0. Patterns receive no suffix stripping.

4. **R4, R6, R12–R13:** `/` alone has zero segments and is valid. Reject internal empty segments at their start (`/a//b` → 3, `//` → 1). Validate preceding segments before rejecting a non-root trailing slash at its final byte; `/%GG/` fails at 1.

5. **R7, R12, R20:** Raw segment data permits only ASCII unreserved bytes, case-sensitively. Report the first invalid byte using original UTF-8 byte offsets. Raw punctuation, whitespace, and non-ASCII are invalid; `.` and `..` remain ordinary segments.

6. **R8:** Every escape requires exactly two uppercase hexadecimal digits and must decode to printable ASCII excluding `/` and all unreserved bytes. Every malformed or prohibited escape fails at its `%`, including lowercase hex, truncated escapes, `%2F`, `%41`, `%7F`, and `%80`.

7. **R8, R20:** Decode exactly once for comparison and capture. `%25` produces a literal `%`; `%252F` produces literal `%2F`, with no second decoding. Escaped `?` and `#` are data, and decoded punctuation must not become capture syntax or separators.

8. **R9–R12:** Only a raw `:` or `*` at a pattern segment’s beginning introduces a capture; the entire remainder is its name. Enforce `[a-z][a-z0-9_]*`, including rejecting empty names. Malformed or duplicate names fail at the marker, even when a later name byte resembles a malformed escape.

9. **R10–R13:** Parameters and wildcards share one duplicate-name namespace per pattern. Validate segments left to right. A non-final wildcard fails at its own start before examining later segments. Despite R11’s optional-slash wording, R13 forbids every non-root trailing slash.

10. **R9, R14–R15, R20:** Parameters consume exactly one nonempty decoded segment. Wildcards consume zero or more complete remaining segments, joined by `/`; zero consumption still returns an empty capture and requires no extra slash. Return captures in pattern order, excluding statics, with each registered route’s own names.

11. **R16–R17:** Compare specificity vectors lexicographically: static `2`, parameter `1`, wildcard `0`; append terminal `3` only without a wildcard. The wildcard ends the vector. Earlier-position specificity dominates total static counts; an exact route beats an empty wildcard, and equal vectors use registration order.

12. **R3, R12, R18–R20:** Fully validate every request before returning a match or `NotFound`, even with an empty router or an early matching wildcard. Require complete matching, with no implicit prefix matching or normalization. Resolve must remain read-only and repeatable; parsing errors must use the correct pattern/path error variant.
