1. **R1–R3:** Deliver one std-only Rust source file in `rust` fences, compiling with edition 2024; preserve the exact public API, field types, variants, and derives. No inner attributes or inner doc comments.

2. **R4, R6:** Check length first: 0 and 32 are allowed; 33 or more returns `RowTooLong` with the actual length, regardless of invalid cells or possible overflows.

3. **R5–R6:** Validate cells in increasing original index for either side. Valid values are exactly 0 and powers of two from 2 through 2147483648; 1 is invalid. Report the earliest invalid index before attempting any merges.

4. **R7, R20:** Never mutate the input; successful cells are owned and retain its length. Empty, all-zero, and valid one-cell rows succeed unchanged on either side.

5. **R8–R9:** Ignore zeroes when finding adjacent tiles, but retain original indices. Left scans increasing indices; Right scans decreasing indices.

6. **R10:** Greedily merge equal neighbors once, consuming both; never reconsider their output. An unequal comparison advances only past the leading tile: `[2,4,4]` moved Left becomes `[2,8,0]`.

7. **R10, R20:** Three equal tiles merge the destination-most pair; four equal tiles produce two separate merges. Continue processing regardless of whether a conventional target such as 2048 appears.

8. **R11–R12:** A standalone 2147483648 tile is valid; pairing two causes `MergeOverflow`. Report the first overflowing pair in destination scan order, using original indices in that order, and return no partial result.

9. **R13, R15:** Pack outputs starting at the destination edge; `Merge.to` is the final compacted index. For Right, output positions descend from `len - 1`; zeroes fill the unused left portion.

10. **R14–R16:** Preserve scan order both within `from` and across `merges`. For `[2,2,2,2]` moved Right, records are `from:[3,2], to:3` followed by `from:[1,0], to:2`, each with value 4.

11. **R15, R17:** Each merge records its doubled value; score sums those new values only, using `u64` arithmetic. The score can exceed `u32::MAX` even when every individual merge succeeds.

12. **R18–R19:** Determine `changed` by exact cell-vector comparison with the input. Sliding without merging can change cells with score 0; an unchanged success must have score 0 and no merge records.
