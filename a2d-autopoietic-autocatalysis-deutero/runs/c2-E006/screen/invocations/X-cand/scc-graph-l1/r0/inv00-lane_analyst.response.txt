1. **R1–R2:** Submit one std-only Rust source file in `rust` fences, compilable with edition 2024; no inner attributes or inner docs. Match the public API exactly, including constants, field types, variant fields, and derives; keep helpers private.

2. **R4–R6:** Validation precedence is strictly vertex count, then edge count, then endpoints. An earlier category wins regardless of errors in later categories; validate before graph analysis.

3. **R4–R5, R14:** Both limits are inclusive: 4096 vertices and 32768 input edges are allowed. Count every edge occurrence, including duplicates and self-loops.

4. **R6–R7:** Scan edges in original slice order, checking each source before its target. Return the earliest offending edge, with side 0 winning if both endpoints are invalid; preserve the original index and offending value.

5. **R6–R7, R18:** Endpoint validity is precisely `vertex < n`. `usize::MAX` is an ordinary invalid value; validation must not overflow, index with it, or alter it before reporting the error.

6. **R3, R8–R9:** Compute directed strongly connected components, including every isolated vertex. Zero-length self-reachability does not make vertices connected to others or make a singleton cyclic.

7. **R9–R10:** Components must be maximal, nonempty sets, each represented by distinct vertex numbers in ascending order. Every vertex appears in exactly one component.

8. **R11–R12:** Sort components by size descending, breaking ties by smallest member ascending. IDs are positions after this sort; rebuild `component_of` accordingly, with exactly n entries.

9. **R13–R14:** Align `cyclic` with the final component order. It is true exactly for components of size at least two or singletons with a self-loop; incoming/outgoing edges and repeated non-loop edges do not qualify.

10. **R4–R6, R15:** For n = 0, empty edges produce three empty vectors. A nonempty list within the edge limit fails at edge 0, source side 0; an over-limit list still returns `TooManyEdges` first.

11. **R3, R16–R17:** With no edges and n > 0, return singleton components in vertex order, identity `component_of`, and all-false `cyclic`. Valid edge permutations and duplicates must leave all three outputs unchanged; calls have no persistent state and return owned values.

12. **R18:** Support maximum-size paths, disconnected graphs, and one SCC containing all vertices without panics. Traversal depth and resource use must remain safe at the limits; the visible tests exercise none of these stress cases.
