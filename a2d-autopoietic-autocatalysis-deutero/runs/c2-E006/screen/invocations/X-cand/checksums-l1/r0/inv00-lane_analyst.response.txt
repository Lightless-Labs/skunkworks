1. **R1–R2:** Deliver one Rust 2024, std-only source file inside `rust` fences, without inner attributes or inner doc comments. Every specified type, function, and struct field must be public; all specified types require all five listed traits.

2. **R3–R4:** CRC uses the reflected IEEE algorithm exactly: initial/final XOR `0xffffffff`, eight right shifts per byte, and polynomial `0xedb88320` conditioned on the **old** low bit. Empty input returns 0; zero and high-bit bytes are ordinary unsigned bytes.

3. **R5–R6:** Adler starts at `(a,b)=(1,0)` and updates `b` using the newly updated `a`. Reduce modulo **65521**, prevent overflow even on long inputs, and return `(b<<16)|a`; empty input returns 1.

4. **R7:** `checksums` must match the two standalone functions exactly. Results are integer values, with no host-endian conversion or byte serialization.

5. **R8, R16:** Spans select half-open ranges and hash their concatenation in supplied order, excluding gaps. Carry both algorithms’ internal states across boundaries; do not reset per span or combine finalized checksums naively.

6. **R9:** The earliest invalid span by supplied index wins. Complete that span’s ordered checks before considering later spans; a later reversed or bounds error cannot supersede an earlier overlap.

7. **R10:** Within a span, `start > end` always returns `Reversed { span: index }`, even if one or both endpoints also exceed the data length.

8. **R11–R12:** Next check `start > len`, then `end > len`, returning the actual offending endpoint as `offset`, not its excess beyond the length. Bounds errors precede overlap; endpoints equal to `len` are valid, including `usize::MAX` inputs being handled without arithmetic overflow.

9. **R12, R14:** After bounds checks, require each span’s start to be at least the immediately preceding span’s end. Equality permits adjacency; compare positions regardless of identical contents, and never sort or coalesce spans.

10. **R13–R14:** Empty spans participate as both current and preceding spans. An empty span inside the preceding span overlaps; one in a gap establishes its position as the next ordering boundary. Repeated empty spans at the same position are valid.

11. **R13, R15:** Empty spans still require full validation. Only a **valid** all-empty collection, or no spans, returns `{ crc32: 0, adler32: 1 }`, regardless of unselected data; empty data does not make nonzero endpoints valid.

12. **R17–R18:** Malformed spans must return the specified error without panicking. Calls must preserve inputs and expose no state changes, run in linear time in selected bytes plus span count, and use bounded auxiliary space without copying the concatenation.
