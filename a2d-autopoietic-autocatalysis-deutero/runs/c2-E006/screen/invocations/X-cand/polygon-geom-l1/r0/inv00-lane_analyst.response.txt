1. **R1–R2:** Submit one Rust source file in a `rust` fence, compatible with edition 2024 and std only, with no inner attributes or inner documentation. Match the public API and required derives; do not add public API items.

2. **R3, R16:** Both coordinate bounds are inclusive. Reject even `i64::MIN` and `i64::MAX` without overflow or panic; avoid unchecked absolute values or arithmetic before validation. Use sufficiently wide integer intermediates for all subsequent calculations.

3. **R4–R7, R16:** Error precedence is strictly: excessive **raw** length, first invalid **raw** vertex, then insufficient **effective** length. Exactly 4096 raw vertices are permitted; 4097 fails even if removing a closure would leave 4096.

4. **R5:** Scan vertices in input order and check both coordinates, including the closing vertex. Return its original raw index for the first invalid vertex, even when the polygon is otherwise too short.

5. **R6–R7:** Remove exactly one final point only when raw length is at least two and first equals last. Empty input stays length 0; a singleton stays length 1; two equal points become length 1. Additional closure copies remain.

6. **R6, R8, R15:** Preserve effective vertex order and every remaining duplicate. Produce exactly one edge per effective vertex, including the closing edge; edge lengths and returned indices follow that order, without canonicalization.

7. **R7, R9:** Three effective vertices suffice regardless of geometry. Accept identical vertices, zero-length edges, collinearity, concavity, and self-intersection; do not impose distinctness, nonzero area, simplicity, or validation checks.

8. **R10–R11:** Compute the signed shoelace sum first, then take its absolute value for `area2`. Cross-product cancellation is required; zero means `Degenerate`, including self-intersecting polygons with canceling signed areas.

9. **R3, R12:** Round each scaled edge length exactly using integer arithmetic. For `N = d2 * 1_000_000` and `k = floor(sqrt(N))`, round upward precisely when `4N >= (2k + 1)^2`; floating-point approximations cannot decide rounding.

10. **R12–R13:** Zero-length edges contribute 0. `perimeter_milli` sums all individually rounded edge values, including the closing edge; rounding the total geometric perimeter can give the wrong answer.

11. **R2, R14:** Select the longest edge by rounded length. Break ties by lexicographically comparing normalized endpoint pairs `(min_endpoint, max_endpoint)`, then by edge index. Every successful polygon returns `Some(index)`, even when all lengths are zero.

12. **R15–R16:** Leave inputs unchanged and return deterministic results. For translations within the accepted bounds, area and lengths remain unchanged; winding reversal negates signed area while preserving absolute area and perimeter, but edge vectors and indices must reflect the new order.
