1. **R1–R2, R18:** Deliver one Rust 2024, std-only source file inside Rust fences, without inner attributes/docs. Both functions must be public with the exact signatures; the single public `PathError` enum must contain all nine specified variants and derive all four traits.

2. **R3, R12, R24:** Every `at` is a zero-based byte offset in the original input, including bytes before a tilde-expanded remainder. `Escape` points to the first dot of the offending `..`, not its separator or a normalized position.

3. **R4–R7, R21:** Validate the whole raw request before traversal: Empty → first NUL anywhere → first backslash anywhere → first forbidden control anywhere. Error category outranks position; even a later control defeats an earlier root escape.

4. **R7–R8, R17:** Controls are exactly ASCII bytes 1–31 and 127, with NUL handled separately. Preserve spaces, Unicode, percent sequences, case, and ordinary tildes literally; perform no filesystem/environment access. Successful normalization must be idempotent.

5. **R9–R10, R14:** Only an initial slash makes a path absolute. Ignore empty components from every slash run, including leading runs; discard only exact `.` components. Names such as `...` and `.name` remain ordinary.

6. **R11–R13:** `..` pops only an ordinary component, never a retained `..`. Relative unmatched parents accumulate without a specified limit; absolute unmatched parents fail immediately at the earliest traversal event, including after earlier components have canceled.

7. **R14–R16:** Empty reduced results are exactly `/` or `.`. Determine directory intent from the raw ending slash or exact final nonempty `.`/`..`; append one slash only when components remain. Thus `..` → `../`, `a/..` → `.`, and `a/.` → `a/`.

8. **R18–R20, R26:** `normalize` keeps its original behavior. For `resolve`, validate cwd first, then every supplied home—even for absolute requests or unused home. Each context must begin with `/` and normalize successfully; hide all underlying failures as `InvalidCwd` or `InvalidHome`, respectively.

9. **R19–R21, R26:** Error precedence across stages is invalid cwd → invalid supplied home → request lexical errors → tilde/traversal errors. Contexts undergo lexical normalization without tilde expansion and must reject root escapes; `None` alone is a valid home argument.

10. **R21–R22:** Only an initial exact `~` or `~/` expands. Any other byte after an initial tilde yields `UnsupportedTilde { at: 1 }`, including with absent home; recognized expansion with absent home yields `MissingHome`. Request lexical errors beat both.

11. **R19–R20, R23–R24:** Start absolute requests at root, ordinary relative requests at normalized cwd, and tilde requests at normalized home. Treat context components as a directory regardless of trailing slash; consume only the tilde and optional immediate slash, ignoring subsequent empty components. Parents may remove context components but cannot pass root.

12. **R24–R25:** Every successful resolve result is absolute. Trailing-slash intent comes exclusively from the original request: bare `~` has none, `~/` has it, and exact final dot/parent components have it. Context spelling contributes no intent, and root always remains `/`.
