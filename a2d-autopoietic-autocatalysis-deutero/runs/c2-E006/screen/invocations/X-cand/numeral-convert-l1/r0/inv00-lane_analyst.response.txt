1. **R1–R4:** Encoding accepts both endpoints, 0 and 3999; every larger `u32`, including `u32::MAX`, returns `Range`. Zero is exactly `N` or `n`.
2. **R3–R4:** Positive encoding uses the specified greedy token order, including subtractive tokens; lowercase output is the ASCII lowercase spelling.
3. **R5–R8:** Decode does no trimming or normalization. Only the empty string returns `Empty`; whitespace, signs, digits, and non-ASCII characters are invalid bytes.
4. **R7–R8:** Report the earliest invalid UTF-8 **byte offset**, not a character index. For `"IVé"`, return `InvalidByte { index: 2 }`.
5. **R8–R10, R18:** Complete lexical validation before case validation. `"iV!"` returns `InvalidByte { index: 2 }`, despite the earlier case mismatch.
6. **R9:** After lexical validation succeeds, the first byte fixes the case, including `N`/`n`; report the first opposite-case byte, not the first case transition chosen by another rule.
7. **R11–R12, R18:** Only singleton `N` or `n` means zero. Every other input containing either returns `NonCanonical { index: 0 }` after lexical and case checks; `"Nn"` therefore returns `MixedCase { index: 1 }`.
8. **R13:** Provisional evaluation consumes disjoint pairs whenever the immediately following symbol is strictly larger. `"IIV"` evaluates as `1 + 4 = 5`; do not use a general subtract-each-smaller-symbol algorithm.
9. **R13–R14:** Provisional evaluation permits all increasing pairs, even noncanonical ones. `"IM"` provisionally equals 999 and proceeds to canonical comparison rather than failing during arithmetic.
10. **R14, R18:** A provisional sum above 3999 returns `Range` even for malformed spelling, such as `"MMMM"`. Arbitrarily long input must not overflow; saturating at 4000 is permitted.
11. **R15–R17:** For an in-range value, require exact equality with its greedy encoding in the detected case. Pair and repetition checks alone are insufficient; report the first differing byte, or the shorter length for a prefix mismatch (`"IIII"` fails at index 1).
12. **R18; public API:** Both functions must be deterministic and stateless. Preserve every specified public name, signature, variant, and field; derive all four requested traits on both enums, and satisfy the single-file, edition-2024, std-only constraints.
