1. **R1:** Deliver one std-only source file compiling under `rustc --edition 2024`, inside a single `rust` fence. Preserve every specified public type, derive, variant, and method signature; keep storage private and omit inner attributes/doc comments.

2. **R3, R18:** Every operation validates the entire path before lookup. The first NUL wins over all other defects, even an earlier relative-path or component defect; its index is a UTF-8 **byte** offset. Without NUL, empty or relative paths yield `InvalidPath(0)`.

3. **R4:** Except for `/`, reject empty, `.` and `..` components, selecting the first invalid component left to right. Empty interior components report their terminating slash; trailing emptiness reports the final slash. Thus `/a//b` reports 3, `/a/` reports 2, and `//` reports 1. Never normalize these away.

4. **R16:** Accept every other component verbatim: whitespace, Unicode, backslashes, `.hidden`, `...`, and embedded dots are legal. Only `/` separates components; names remain case sensitive and untrimmed.

5. **R5, R18:** Traverse prefixes in order. Report the first missing prefix or the first file that blocks further traversal, before considering the final entry. With file `/a`, accessing `/a/b/c` yields `NotDir("/a")`; with absent `/a`, it yields `Missing("/a")`. Error strings are absolute canonical prefixes without trailing slashes except `/`.

6. **R6–R7, R17:** Creation never creates ancestors. Check the parent before the final entry, including `NotDir(parent)` when the immediate parent is a file. `mkdir` creates only its requested directory; an existing final file **or** directory yields `Exists(path)`, never success or conversion.

7. **R6, R8, R13, R17:** `write` alone may create a missing final file during ordinary lookup. It replaces an existing file’s entire contents, truncating for shorter or empty data, and copies the input bytes. An existing final directory yields `IsDir(path)` and remains intact.

8. **R9, R12–R13:** `read` returns all bytes unchanged, including NUL and invalid UTF-8, as an independent owned vector. Final directories yield `IsDir(path)`; absent files yield `Missing(path)`. Neither later input-buffer changes nor returned-buffer changes may affect stored contents.

9. **R10, R12, R15:** `ls` on a final file yields `NotDir(path)`; a missing target yields `Missing(path)`. Return only immediate child basenames and stored kinds, excluding the directory itself and deeper descendants. Empty directories return an empty vector; returned vectors and strings are independent of storage.

10. **R11:** Sort children ascending by Rust `String` ordering, case sensitively and independently of insertion order. Do not use locale, case-insensitive, natural-number, or kind-first ordering.

11. **R2, R4, R14:** Each fresh instance contains exactly the empty root directory and is independent, with no host filesystem access. Root `mkdir` yields `Exists("/")`; root `write`/`read` yield `IsDir("/")`; root `ls` lists children. The root-resolution wording does not legalize paths rejected by R4.

12. **R12, R17:** Every failed mutation leaves the entire filesystem unchanged; successful operations preserve unrelated entries. No valid UTF-8 path or byte payload may trigger a panic, including empty inputs and multibyte names; avoid character-index slicing and unchecked offset arithmetic. No additional path or data size limit is specified.
