1. **R1–R2, R18, R27, R38, R49:** Preserve every specified public signature, field, variant and derive in one cumulative implementation. Use one Rust 2024 source file, std only, with no inner attributes/documentation. Do not impose fixed limits on path length, components or table size; `max_expansions` limits only link expansions.

2. **R3–R8, R21:** Validate the entire raw input before traversal: Empty → first NUL anywhere → first backslash anywhere → first forbidden ASCII control anywhere → traversal errors. These categories override earlier-position errors of lower priority. Offsets are original UTF-8 byte offsets. Preserve spaces, percent escapes, Unicode, case and literal tildes.

3. **R9–R14, R17:** Only an initial slash makes a path absolute; multiple leading slashes still mean one root. Ignore empty components and exact `"."` only. `".."` removes an ordinary component, never another retained parent. Relative unmatched parents accumulate; absolute unmatched parents fail immediately at that parent’s first byte. Empty results are `/` or `.`. Successful normalization must be idempotent.

4. **R15–R16, R25:** Compute directory intent from the original request: terminal slash, or last nonempty component exactly `"."` or `".."`. Append one slash only when components remain, never to root or empty-relative dot. Thus `..` becomes `../`, `a/..` becomes `.`, and `a/.` becomes `a/`. Context and target spellings cannot contribute intent.

5. **R18–R26:** Resolve validates cwd first, then every supplied home, even for absolute requests; require absolute spelling and successful normalization, wrapping every underlying failure as InvalidCwd/InvalidHome. Context validation never expands tilde. Then validate request bytes before tilde handling. Only `~` and `~/` expand; missing home yields MissingHome, while any other leading-tilde form yields UnsupportedTilde at byte 1, even without home. Resolve is lexical and always absolute.

6. **R27–R30:** `resolve_links` validates cwd → home → entire table → request. Check entries in slice order. Keys must equal their successful normalization exactly, be absolute, non-root and lack trailing slash. Targets need only raw lexical validation. Validate both fields before checking duplicates; invalid fields beat duplication within that entry. DuplicateLink identifies the first matching index and current index. Never sort.

7. **R23–R24, R31–R32:** Traverse normalized cwd/home components from root before request components; absolute requests omit context components. Context component offsets are zero; request offsets retain the original spelling, including tilde prefixes and repeated slashes. Every ordinary push immediately triggers link lookup, before any following dot or parent. Dot/parent processing itself never triggers lookup.

8. **R33–R34, R37:** Relative targets start at the matched link’s parent; absolute targets clear the stack. Process target components, including nested expansions, before resuming the interrupted stream. Target tildes remain literal; target Escape offsets are local to that target. Do not pre-normalize or speculatively traverse targets: unreachable cycles and escapes are valid table contents, and traversal order determines the error.

9. **R35–R37, R49:** Keep a link active through its entire target and nested expansions, then deactivate it before resuming subsequent components. Repeated completed visits are allowed and cost expansions again. At each match, check active membership first, then exhausted budget, then increment: Loop beats Limit. Zero permits link-free traversal. Avoid implementation recursion limits becoming artificial component or expansion caps.

10. **R38–R41, R48:** Resolve base first and propagate its error before independently resolving target against the same original cwd/home. Each gets fresh expansion state. Treat resolved base as a directory regardless of its slash. Routes compare whole components, strip the longest common prefix, then emit parents plus destination suffix; an empty route is dot.

11. **R42–R43:** Include the direct route, then probe each original absolute link key independently using cwd `/`, home None, the full table and a fresh budget. Silently skip every probe error. A successful probe contributes only when its resolved components prefix target, including root or full equality. Route to the original key and append the unmatched target suffix, replacing a dot route when that suffix is nonempty. Never combine shortcuts recursively.

12. **R44–R48:** Before ranking, protect candidates beginning with tilde using `./`; introduce no other leading `./`. Append a slash to every candidate except dot exactly when resolved target ends in slash, including root. Validate every candidate—even direct—against resolved base with supplied home/table and fresh state; compare resolved components, ignoring trailing slash. Rank valid spellings by UTF-8 byte length, then UTF-8 byte lexicographic order, counting protective prefixes and trailing slashes. Results remain relative; duplicates and table order cannot affect selection.
