1. **R1–R2, R19, R30–R31, R34, R39, R45, R50:** Requirements are cumulative: retain every earlier API with exact names, types, signatures, public fields and required traits. `Stream` fields stay private; it requires `Debug, Clone`. Deliver one std-only Rust 2024 source file in Rust fences, without inner attributes or inner doc comments.

2. **R3–R7, R16–R18:** CRC-32 uses reflected polynomial `0xedb88320`, initial/final xor `0xffffffff`; Adler starts `(a,b)=(1,0)` and updates `b` using the new `a`. Empty results are CRC `0`, Adler `1`. Process all binary bytes unsigned, return numeric values independent of host endianness, and prevent overflow on long inputs. Calls must preserve inputs and have no observable external state.

3. **R8–R12, R17:** Validate spans in supplied order; the earliest failing span wins. Within that span check strictly: reversed → start out of bounds → end out of bounds → overlap with the immediately preceding end. Equality with `data.len()` is valid; report the offending endpoint itself. Never sort, coalesce, or slice invalid ranges and panic.

4. **R8, R12–R16, R18:** Empty spans participate as both predecessor and successor: one inside a preceding nonempty span overlaps, while one in a gap advances the boundary. Adjacency and repeated empties are valid. Hash only the supplied-order concatenation, excluding gaps, initializing once. No spans or only valid empties yields `(0,1)`; use linear time and bounded space without copying concatenated bytes.

5. **R20–R25, R30:** Seeds are finalized checksums: undo CRC’s final xor and unpack Adler directly, without adding another initial `1`. Check `a<65521` before `b<65521`; CRC accepts every `u32`, and Adler seed `0` is valid. Empty updates preserve arbitrary valid seeds. `update_spans` must leave both components unchanged on any error. Reads preserve state, clones evolve independently, and reset always restores standard empty state.

6. **R26–R29:** Snapshots are exactly 19 ASCII bytes, `c` + eight lowercase CRC digits + `:a` + eight lowercase Adler digits, including leading zeroes. Restore checks byte length and markers first, then every digit in absolute-offset order, then Adler validity with component `0` before `1`. A later bad digit outranks an earlier numerically invalid Adler component. Handle Unicode safely using byte offsets.

7. **R31–R33, R41:** Fletcher-16 starts at zero and reduces modulo `255`; Fletcher-32 starts at zero and reduces big-endian words modulo `65535`. Zero residues must be `0`, including contributions from `0xff` bytes or `0xffff` words. Carry a pending high byte across gaps and empty spans; pad once, only at the logical concatenation’s end. Empty results are zero; long-input arithmetic must remain exact with bounded space.

8. **R34–R40:** Xmodem and False use left shifts and `0x1021`, with initial registers `0` and `0xffff`, respectively, no reflection/final xor, and 16-bit truncation. X25 uses right shifts, `0x8408`, initial/final xor `0xffff`, and no byte swap. Empty results are `0`, `0xffff`, `0`. `multi_checksums` applies the same span validation and all five algorithms to one logical concatenation, without boundary resets or padding.

9. **R42–R44:** Combining accepts arbitrary finalized `u32` arguments, not merely checksums of known blocks. For positive length, apply the raw zero-byte linear operator to `left` exactly `right_len` times algebraically, then xor `right`; do not introduce extra initialization/finalization. Zero length returns `left` regardless of `right`. Support all 64 length bits in logarithmic time and bounded memory.

10. **R45–R48, R56:** `combine_parts` must finish a checked, supplied-order length scan before inspecting any CRC metadata: the first overflow outranks every invalid empty CRC, even an earlier one. Then report the first zero-length part whose CRC is nonzero; nonempty CRCs are unrestricted. Combine in order from CRC `0`; valid empty parts are identities, and no parts returns `{crc32:0,len:0}`. Bound work by parts × 64 and auxiliary space by a constant.

11. **R49, R55–R56:** Manifest length counts selected bytes only. Output exactly 48 ASCII bytes: `len=` + 16 lowercase hex digits + `;crc=` + eight + `;adler=` + eight, all zero-padded. Empty selection encodes length `0`, CRC `0`, Adler `1`. Preserve normal span errors and use linear time with bounded space except the returned fixed-size string.

12. **R50–R56:** Verify precedence is span error → shape → first bad hex byte → length mismatch → CRC mismatch → Adler mismatch. Shape requires 48 bytes and exact markers at `0..4`, `20..25`, `33..40`; digit offsets are `4..20`, `25..33`, `40..48`. Validate all digits before comparing values; accept only lowercase ASCII hex, with no trimming or normalization. Parse length as `u64`; any well-formed unequal value gives `Length`. Mismatch fields are CRC `0`, Adler `1`, with `expected` from the token and `actual` computed. Token Adler components need no seed validation; Unicode must never cause a panic.
