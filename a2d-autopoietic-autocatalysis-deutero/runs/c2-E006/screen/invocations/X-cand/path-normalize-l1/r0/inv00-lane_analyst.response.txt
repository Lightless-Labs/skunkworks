1. **R1–R2:** Deliver one Rust source file in a `rust` fence, compatible with edition 2024 and std only. No inner attributes/docs. Expose the exact function and public enum, with all five specified variants, `usize` offsets, and all four derives.

2. **R3:** Every error offset counts UTF-8 bytes in the original input, including skipped slashes and components. Multibyte characters affect subsequent offsets; normalization must not change reported positions.

3. **R4–R7:** Check in this order: empty input, first NUL anywhere, first backslash anywhere, first forbidden control anywhere, then component reduction. Error category precedence overrides position: a later NUL beats an earlier backslash, control, or escape.

4. **R7–R8:** Controls are exactly ASCII bytes 1–31 and 127, with NUL handled separately. Spaces, non-ASCII control characters, Unicode, percent sequences, and tildes remain literal; perform no trimming, decoding, case folding, or Unicode normalization.

5. **R9, R14:** Absolute means the original first byte is `/`. Any number of leading slashes denotes one root; repeated internal or trailing separators create no components. An all-slash input returns `/`.

6. **R10:** Discard only components exactly equal to `.`. Names such as `...`, `.hidden`, and `a..` remain ordinary components; process components left to right.

7. **R11, R13:** `..` removes only a preceding ordinary component, never a retained `..`. Relative unmatched parents remain, without a specified count limit; for example, `a/../../b` becomes `../b`.

8. **R4–R7, R12:** After raw validation succeeds, an absolute unmatched parent fails immediately at that parent’s first byte. The earliest escape wins, even if later names could supply components; `/../a` cannot recover.

9. **R14:** Join surviving components with single slashes and add exactly one leading slash for absolute paths. Zero surviving components produce `/` when absolute and `.` when relative, including dot-only and fully cancelled paths.

10. **R15:** Determine directory intent from the raw input: it ends in `/`, or its last nonempty component is exactly `.` or `..`. Do not infer intent from the final surviving component.

11. **R16:** Append exactly one trailing slash when intent is true and components survive, including retained parents: `..` → `../`, `../..` → `../../`, `a/.` → `a/`, `a/b/..` → `a/`. Never append to root or an empty relative result; `a/..` → `.`.

12. **R3, R13, R17:** Impose no arbitrary length or parent-count cap, and avoid truncating or overflowing byte-offset arithmetic. Read no filesystem or environment; successful outputs must normalize identically again, including trailing slashes and retained parents.
