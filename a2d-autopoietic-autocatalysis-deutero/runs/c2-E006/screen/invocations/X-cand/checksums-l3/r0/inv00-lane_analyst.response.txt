1. **R1–R2, R19, R30, R34, R39:** Preserve every earlier API while adding later ones, with exact public names, signatures, fields and variants. Required value types/errors implement all five listed traits; `Stream` needs Debug and Clone with private fields. Deliver one std-only Rust 2024 source file in Rust fences, without inner attributes or inner doc comments.

2. **R3–R7, R16:** CRC-32 uses the old low bit to decide each polynomial xor, with initial/final xor `0xffffffff`. Adler updates `a` before `b`, reducing exactly without overflow. Empty results are CRC 0 and Adler 1. Process unsigned binary bytes, including zero/high bits; return numeric values independent of host endianness.

3. **R9–R12, R17:** Validate each supplied span completely before considering the next: reversed, start bounds, end bounds, then overlap. The earliest failing span wins over every later error. Bounds use strict `>`; report the offending endpoint value, not its position. Never slice before validation or panic on malformed endpoints, including `usize::MAX`.

4. **R12–R14:** Compare each start against the immediately preceding span’s end, including empty spans on both sides. Equality permits adjacency and repeated empties. An empty span inside its predecessor overlaps; one in a gap establishes its own ordering boundary. Identical selected contents do not excuse invalid ordering.

5. **R8, R15–R18, R30, R33, R40–R41:** Hash the logical concatenation in supplied order, excluding gaps, without sorting, coalescing, resetting between spans or copying concatenated bytes. No spans/all valid empty spans produce the corresponding empty-input checksums. Processing must be linear with bounded auxiliary space, without retaining inputs, modifying slices or externally observable side effects.

6. **R20–R23, R29:** Seeds are finalized checksums: undo only CRC’s final xor; unpack Adler’s low half as `a` and high half as `b`, without adding 1. Each must be strictly below 65521; invalid `a` wins over invalid `b`. Every CRC and Adler seed 0 are valid. An empty update must preserve any valid seed exactly.

7. **R20, R23–R25, R29:** Updates append identically under every chunking, including empty chunks. `checksum` and `snapshot` do not finalize or mutate stored state. `update_spans` must leave both components unchanged on any error, even after valid earlier spans. Reset always restores standard empty state; cloned streams evolve independently.

8. **R26:** Snapshot format is exactly 19 ASCII bytes: lowercase `c`, eight lowercase hexadecimal digits of finalized CRC, `:a`, then eight lowercase hexadecimal digits of packed Adler. Preserve leading zeroes; include no whitespace, prefixes or newline.

9. **R27–R29:** Restore checks byte length and literal bytes at offsets 0, 9 and 10 before any digits. After shape passes, scan offsets 1–8 then 11–18; accept only ASCII lowercase hex and report the first bad byte offset. Validate every digit before seed validity, then apply Adler `a`-before-`b` precedence. Avoid UTF-8 character indexing that could panic.

10. **R31–R33, R41:** Fletcher-16 consumes bytes modulo 255; Fletcher-32 consumes big-endian words modulo 65535. Both begin at zero and use updated `a` when updating `b`. Zero residues remain zero, including for `0xff` bytes/`0xffff` words; long inputs must not overflow. Fletcher-32 carries a pending high byte across all spans and pads once, only if total selected length is odd.

11. **R34–R38:** Xmodem and False use left shifts, old top-bit decisions and polynomial `0x1021`, truncating to 16 bits; their initial states are 0 and `0xffff`. X25 uses right shifts, old low-bit decisions, `0x8408`, and initial/final xor `0xffff`; do not swap its result bytes. Empty results are respectively 0, `0xffff`, 0.

12. **R33, R39–R41:** `fletcher32_spans` and `multi_checksums` inherit the full span-validation precedence, including empty-span ordering. Multi returns all five algorithms over exactly the same concatenation, with the supplied CRC-16 variant. With no selected bytes, all Fletcher values are 0, base is `(0, 1)`, and CRC-16 retains its variant-specific empty result.
