1. **R1:** Match every public type, derive, variant, and method signature exactly; keep storage private. Deliver one std-only source file compiling with `rustc --edition 2024`, inside Rust fences, without inner attributes or inner doc comments.

2. **R2, R19, R24:** Each new instance contains only root and starts with cwd `/`. Instances are independent and never access the host filesystem. Only successful `chdir` changes cwd.

3. **R3, R18, R23:** Scan the entire original input for NUL before normalization or lookup; the first NUL wins over every other error. Report its original UTF-8 **byte** offset, not character index. Only otherwise reject an empty string as `InvalidPath(0)`.

4. **R4, R19, R21–R22:** Normalize the complete path before lookup. Absolute paths start at root; relative paths start at cwd at operation entry. Remove empty/`.` components and cancel `..` lexically, even after missing or file components; excess `..` stays at root.

5. **R4, R16, R21, R23:** Repeated/trailing slashes are accepted; trailing `/` adds no directory requirement. Only exact `.` and `..` components are special. Preserve whitespace, Unicode, backslashes, case, and all other dot-containing names verbatim.

6. **R5–R6, R18, R23:** Walk normalized prefixes from root. Return `Missing` for the first absent traversed prefix, or `NotDir` for the first file that must be traversed. Parent failures win over final-entry checks; error strings are canonical absolute paths without trailing `/`, except root.

7. **R6–R7, R17:** `mkdir` checks its parent before its final entry, creates exactly one empty directory, and never creates ancestors. An immediate file parent yields `NotDir(parent)`; any existing final entry yields `Exists(final_path)`, including a file.

8. **R6, R8–R10, R20:** After successful parent traversal, a missing final entry is created by `write` or `mkdir`; `read`, `ls`, and `chdir` return `Missing`. Existing final directories yield `IsDir` for read/write; existing final files yield `NotDir` for ls/chdir.

9. **R14, R22:** Apply root rules after normalization: `mkdir` returns `Exists("/")`; read/write return `IsDir("/")`; ls lists root children; chdir succeeds and sets cwd to `/`. Inputs such as `/a/..` must receive these same results.

10. **R9, R12–R13:** Preserve arbitrary bytes, including NUL and non-UTF-8 data. Empty writes create valid files; replacement truncates previous contents completely. Copy data on write and read, and return owned listing names and cwd strings.

11. **R10–R11, R15:** List only immediate children as basenames with their stored kinds; exclude the directory itself and deeper descendants. Empty directories return an empty vector. Sort ascending by Rust `String` ordering, independent of insertion order.

12. **R12, R17, R20, R24:** Every failed mutation must preserve all filesystem state and cwd, including failures after partial traversal. Successful writes/mkdir preserve unrelated entries; failed chdir preserves cwd. Handle all valid UTF-8 paths and arbitrary byte data without panicking.
