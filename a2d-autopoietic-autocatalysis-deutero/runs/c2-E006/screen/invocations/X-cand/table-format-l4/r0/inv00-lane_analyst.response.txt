1. **R1–R2, R33:** Deliver one std-only Rust 2024 source file inside Rust fences, with no inner attributes/docs. Match the API exactly, including all required visibility and derives. Preserve inputs, retain no call state, print nothing, and avoid panics on valid inputs.

2. **R3–R7, R10, R34:** Precedence is absolute: empty-table success → earliest empty row anywhere → earliest ragged row → alignment count → overflow count → Markdown header requirement → insufficient budget → invalid character. Empty tables ignore every option. Empty alignment/overflow vectors mean all Left/Wrap; nonempty vectors must each have exactly n entries.

3. **R11–R12:** Validate original cells in row-major order, then original scalar order. Accept LF and paired CRLF; reject lone CR, every other control, and U+2028/U+2029. Report zero-based original UTF-8 byte offsets, including multibyte prefixes and preceding CRLF pairs; invalid CR points to the CR itself.

4. **R13, R21, R36:** Normalize CRLF, split while preserving every empty logical line, and trim only trailing ASCII spaces from each line before escaping/layout. Empty cells and space-only lines each produce one empty logical line. Preserve leading/internal spaces and accepted non-ASCII whitespace.

5. **R14–R16, R31, R36:** Markdown escapes each original pipe/backslash exactly once into an indivisible two-scalar token. Other scalars are individual tokens; Grid/Compact never escape. Count emitted scalars, including combining marks and zero-width characters. Natural width is the maximum individual logical-line width across header and body, floored at the mode minimum, with no length cap.

6. **R8–R10, R17, R23, R35:** Overhead is `3*n+1` for Grid/Markdown and `2*(n-1)` for Compact; minima are 3 for Markdown, otherwise 1. Reject only nonzero budgets strictly below overhead plus all minima. Shrink the currently widest eligible column one unit per step, choosing the rightmost tie and re-evaluating after each step. Never expand widths; zero and sufficiently large budgets agree. Avoid overflowing arithmetic, including with `usize::MAX` budgets.

7. **R18–R19, R36:** Clip each logical line separately, only when its token width exceeds the allocated width. Reserve one scalar for U+2026, retain the longest initial whole-token prefix fitting the remainder, and stop at the first nonfitting token. Leave unused capacity for padding. An original ellipsis is ordinary content and may appear beside the added ellipsis.

8. **R18, R20–R21, R36:** Wrap greedily by whole tokens, without word-boundary preference, trimming fragment spaces, splitting escapes, or adding ellipses. Exact multiples produce no trailing empty fragment. Each empty logical line produces exactly one empty fragment; concatenate logical lines’ fragments without extra boundary fragments.

9. **R22–R24, R32:** Row height is the maximum cell fragment count; emit matching fragment indices with empty content for exhausted cells. Never carry fragments into another row. Use final widths everywhere, then align: Center puts odd extra padding on the right. Preserve row/column/fragment order and source leading/internal spaces.

10. **R25, R30–R32:** Grid borders use `width+2` hyphens per column; data cells have one surrounding space and literal pipe delimiters. Emit one top and one bottom border. With `header=true`, add a middle border only after all first-row fragments and only if another logical row exists; never separate body rows.

11. **R26, R35–R36:** Compact has neither borders nor header separators and joins aligned columns with exactly two ASCII spaces. Omit only the last column’s right alignment padding, preserving its left padding and source fragment spaces. Do not trim completed lines; earlier padding/joiners can remain at line ends. An empty one-column row emits exactly LF.

12. **R27–R29, R31–R32:** Markdown emits Grid-style data lines without outer borders, followed by exactly one marker after the complete first logical row—even for an empty or sole header. Markers have final column widths: `:` plus hyphens, hyphens plus `:`, or two colons enclosing hyphens. Structural pipes stay literal; multiline cells emit successive physical lines. Every emitted line ends with exactly one LF, with no extra blank lines.
