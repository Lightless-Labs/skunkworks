1. **R1–R2:** Deliver one std-only Rust source file inside `rust` fences, compiling under edition 2024, without inner attributes or inner documentation. Expose the exact specified public API and trait implementations; keep Router fields and additional helpers private. No `main` is required.

2. **R3, R19:** IDs count successful additions only, starting at zero. Any failed addition must leave all state unchanged. Duplicate and structurally equivalent patterns remain separate registrations with independent capture names; repeated resolution must not mutate state.

3. **R5, R18, R21:** Validate the method first in both operations: exactly nonempty ASCII `[A-Z]+`, including custom methods. Then, for resolve only, truncate at the first raw `?` or `#` before validating the entire remaining head—even with an empty router or an obvious mismatch. Ignored suffixes may contain anything.

4. **R4, R6, R12–R13, R20:** Empty or relative inputs fail at byte 0. `/` alone has zero segments and no trailing flag; other paths may have one trailing slash under every policy. Interior empties fail at their start (`/a//b` → 3, `//` → 1). Never collapse slashes or normalize `.` and `..`.

5. **R7–R8, R12, R20:** Static/request raw bytes must be ASCII unreserved; all other data requires canonical `%HH` with uppercase hexadecimal letters. Decoded bytes must be printable ASCII excluding slash and unreserved bytes. Reject malformed, lowercase, incomplete, noncanonical, or out-of-range escapes at `%`; decode exactly once, so `%252F` becomes literal `%2F`.

6. **R9–R12, R20:** Only a raw leading `:` or `*` marks a pattern capture; its entire remainder must match `[a-z][a-z0-9_]*`. Empty, malformed, or duplicate names fail at the marker, even if the name contains a later bad escape. Parameter and wildcard names share one duplicate namespace; encoded markers in static segments remain literal data.

7. **R10–R12:** Validate segments left to right, reporting UTF-8 byte offsets and the appropriate InvalidPattern/InvalidPath variant. A non-final wildcard fails at its own start before validating later segments; an optional final slash does not make it non-final. Static/request segments report their first bad byte or escape, before any trailing-slash validity check.

8. **R9, R14–R15, R20:** Parameters consume exactly one nonempty decoded segment. Wildcards consume all remaining segments, including zero, joining decoded values with `/`; always return their capture, including `""`. Return captures in pattern order. Match the complete prefix/path, and do not reinterpret captured punctuation as syntax.

9. **R15, R22–R24:** Strict requires equal trailing flags before method selection; Ignore and Redirect disregard flags for candidacy and ranking. A zero-length wildcard consumes no separator: Strict `/assets/*tail` matches `/assets`, while `/assets/` requires a matching trailing flag. Root has no trailing flag.

10. **R16–R17, R19, R27:** Rank method-eligible candidates by lexicographically comparing static=2, parameter=1, wildcard=0, appending terminal=3 only without a wildcard. Stop at the wildcard: exact endings beat empty wildcards, and earlier segment specificity dominates later specificity or total static counts. Equal vectors use earliest successful registration, regardless of capture names or ignored slash flags.

11. **R18, R25–R27:** Build all path candidates first, then filter by method, then rank. HEAD uses explicit HEAD candidates whenever any exist, even below higher-ranked GET candidates; otherwise it uses GET and retains that route’s ID and captures. No candidates means NotFound; candidates but no eligible method means MethodNotAllowed. GET has no HEAD fallback; OPTIONS has no implicit behavior.

12. **R23–R26:** A 405 lists methods from **all** path candidates, including lower-ranked ones, adding HEAD whenever GET appears, then deduplicating and sorting ascending ASCII. Errors never redirect. Redirect policy compares only the selected winner’s slash flag and adds/removes the final slash of the original encoded request head; preserve encoding and case, discard suffixes, and never redirect root. Ignore always returns `None`.
