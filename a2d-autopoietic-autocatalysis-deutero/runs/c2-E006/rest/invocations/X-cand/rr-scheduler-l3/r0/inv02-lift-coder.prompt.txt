R5. Next switch_cost must be 0..=1000, otherwise Error::SwitchCost.

R6. Next jobs.len() must be at most 64, otherwise Error::TooManyJobs.

R7. Next inspect job rows in input order. At each row the first check is whether id equals any earlier row id; if so return Error::DuplicateId { index }.

R8. At that row next require arrival in 0..=1000; otherwise Error::Arrival { index }.

R9. At that row next require level < quanta.len(); otherwise Error::InitialLevel { index }. Level 0 is the highest priority.

R10. At that row finally require ticks in 0..=1000; otherwise Error::Ticks { index }. Zero is valid. Earlier row errors win over any later row errors.

R11. Start at time 0. External arrivals are admitted by increasing (arrival, input index), regardless of input sorting or id values.

R12. A zero-tick job completes at its exact arrival time, including during another job's Run or dispatch cost. It never enters a ready queue, creates a Run, or changes the last dispatched id.

R13. There is one FIFO ready queue for each level. An external arrival joins the tail of its initial level queue.

R14. Choose the head of the lowest numbered nonempty queue whenever a dispatch is needed. A higher-priority arrival never interrupts a selected dispatch.

R15. At the start of each scheduling iteration, admit every pending event whose timestamp is at most the current time before selecting a job. Events retain their own timestamp even when processed later.

R16. Remove the selected head before charging any cost. This choice is locked: events during a dispatch cost may join queues but cannot replace the selected job.

R17. Before executing the selected job, add switch_cost to time exactly when a last positive-work dispatch id exists and differs from the selected id. The first dispatch is free.

R18. Admit events through the time after that cost. Then execute uninterrupted for min(remaining CPU work, selected quantum). Cost does not consume quantum.

R19. The selected quantum is quanta at the job's level when selected. Run.level is that level, before any demotion or promotion.

R20. Advance time by consumed CPU ticks. Emit exactly one Run, with start after cost, end after execution, and finished true exactly when the entire job completes. Never merge Runs, including adjacent Runs of the same id.

R21. After execution, admit all pending events through the Run.end, including events exactly at Run.end, before requeuing the running job. Arrivals during execution are never delayed until its next dispatch.

R22. If unfinished, demote the running job by one level, capped at the last level, and append it to that level's tail after all newly admitted arrivals. Every unfinished dispatch demotes, including one at the bottom level.

R23. A finished job leaves permanently and completes at Run.end; it is not requeued. A job finishing exactly at a quantum boundary is finished.

R24. After execution, remember its id as the last dispatched id. Consecutive dispatches of the same id incur no cost, even if zero-work arrivals occurred between them.

R25. If no ready job exists but an event remains, advance to the next event timestamp. Any positive time skipped is idle: append that half-open interval and clear the last dispatched id. The next dispatch after positive idle is free.

R26. Merge adjacent idle intervals into one pair when the old end equals the new start. Never include dispatch costs in idle, never emit zero-length idle, and emit no trailing idle after the last completion.

R27. Schedule.end is the time all jobs have completed. Initial idle begins at 0 when needed. For no jobs, end is 0 and all vectors are empty.

R28. Schedule.completion has exactly one (id, completion_time) per input job in input order, regardless of execution or completion order.

R29. All time and statistics calculations are exact u64. The stated bounds guarantee no overflow; no wall-clock, randomness, threads, global state, or external services affect the result.

8. **R18–R20, R23:** Execute `min(remaining, quanta[selected_level])` uninterrupted. Emit exactly one Run per dispatch, starting after cost, recording the selected level, and marking finished even on an exact quantum boundary. Never merge adjacent Runs of the same ID.

12. **R26–R27:** Stop when all jobs have completed, without trailing idle. End includes necessary idle leading to a final zero-work arrival, even if the last Run ended earlier. Initial idle starts at 0; valid empty input returns end 0 and three empty vectors.
