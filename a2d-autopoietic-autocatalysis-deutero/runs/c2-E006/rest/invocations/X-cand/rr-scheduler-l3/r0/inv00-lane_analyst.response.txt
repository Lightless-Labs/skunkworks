1. **R1, R29:** Preserve the exact public API, field types, and required derives; use one Rust 2024 source file and std only. Do not mutate jobs or retain state between calls. IDs 0 and `u32::MAX` are valid; perform time calculations in exact `u64`.

2. **R2–R6:** Validate parameters even for empty jobs, strictly in this order: level count 1–8; first invalid quantum by ascending index (valid 1–1000); switch cost (valid 0–1000); job count (valid 0–64). Inclusive maximum values are valid.

3. **R7–R10:** Validate rows in input order, completing each row’s checks before advancing: duplicate ID against earlier rows, arrival, initial level, ticks. Thus an earlier row’s ticks error beats a later duplicate. Arrival and ticks allow 0–1000; level must be strictly below the level count, even for zero-tick jobs.

4. **R11–R13, R15:** Admit arrivals by `(arrival, input index)`, never by ID. At every iteration, admit all events with timestamps ≤ current time. Positive-work arrivals append to their initial queue; zero-work jobs complete at their original arrival timestamp even when processed later.

5. **R12, R24:** Zero-tick jobs never enter queues, emit Runs, trigger switch costs, or change the last dispatched ID. This applies during execution and dispatch cost, including when all jobs have zero ticks.

6. **R13–R16:** Dispatch the FIFO head of the lowest numbered nonempty queue. Remove and lock that selection before charging cost; higher-priority arrivals during cost or execution cannot replace or interrupt it.

7. **R17–R18, R24–R25:** Charge exactly one switch cost only when a remembered positive-work dispatch ID differs from the selected ID. First dispatch, repeated dispatches of the same ID, and dispatch after positive idle are free. Admit events through the post-cost time before execution; cost consumes no quantum.

8. **R18–R20, R23:** Execute `min(remaining, quanta[selected_level])` uninterrupted. Emit exactly one Run per dispatch, starting after cost, recording the selected level, and marking finished even on an exact quantum boundary. Never merge adjacent Runs of the same ID.

9. **R21–R22:** Admit every arrival through Run.end, including equality, before requeuing. An unfinished job moves down exactly one level, capped at the bottom, and joins that queue’s tail behind all arrivals admitted during the dispatch.

10. **R12, R23, R28:** Finished positive-work jobs complete at Run.end and leave permanently. Completion contains exactly one entry per input job, in input order—not execution, ID, or completion-time order—including zero-work jobs.

11. **R25–R26:** When queues are empty, jump only to the next pending event. Record every positive skipped interval as idle and clear the remembered ID; zero-length skips do neither. Merge touching idle intervals, including gaps separated solely by zero-work arrivals. Dispatch costs are never idle.

12. **R26–R27:** Stop when all jobs have completed, without trailing idle. End includes necessary idle leading to a final zero-work arrival, even if the last Run ended earlier. Initial idle starts at 0; valid empty input returns end 0 and three empty vectors.
