1. **R1:** Deliver one std-only Rust source file in `rust` fences, compiling under edition 2024. Implement every listed function; expose every specified API item, variant and field with the required derives. No inner attributes or inner documentation.

2. **R2–R6, R15–R18:** Preserve Unicode, whitespace, case and backslashes exactly. Ignore exactly one initial BOM, while retaining its bytes in offsets. Empty/BOM-only input has no records; each terminator creates a record, but no extra record follows a final terminator. Preserve trailing empty fields: `,` has two fields; `""` is one empty field and one record. Calls are independent, with no undocumented size limits.

3. **R7–R12, R16:** Quotes open only at the first field byte; leading whitespace makes a later quote unexpected. Within quotes, doubled quotes decode once, and every newline—including bare CR—is literal. A doubled quote at EOF leaves the field unclosed; a closing single quote at EOF is valid. After closing, only delimiter, LF, CRLF or EOF is legal, with no intervening whitespace.

4. **R3, R7, R10, R12–R14:** Scan left to right, checking NUL first at each byte and outside-quote CR validity before state-specific rules. Thus bare CR after closing quotes is `BareCr`; an earlier lexical error beats a later NUL. Check unclosed quotes only at EOF, reporting the opening quote. Offsets are absolute UTF-8 bytes; record indexes count only consumed outside-quote terminators, with CRLF counting once.

5. **R19–R23, R29:** Validate delimiter range, quote range, then inequality; equality reports `Quote`. Both bytes may be any distinct ASCII bytes `0x21..=0x7e`, including letters. Custom syntax replaces the fixed punctuation everywhere except `parse_csv`. `new` validates immediately; unfinished `feed` only buffers, even malformed/empty chunks. `finish` parses concatenation, caches success or failure, and returns equal clones thereafter; every subsequent feed fails. Reset clears both buffer and cache, preserving Config.

6. **R24–R28:** Reader precedence is invalid config → first lexical error anywhere → duplicate header → first width mismatch. Headers consume the first parsed record, including a blank one; absent records mean `None`. Duplicate rejection selects the earliest second occurrence and its earliest first occurrence. Keep policies preserve all columns. Width checks apply only with headers, using input record indexes starting at 1 for data. Name lookup uses exact values and policy, even for manually constructed tables; it never checks widths.

7. **R30–R32, R36, R41:** Extract data rows and requested specs in their original orders, allowing repeated requests. Error `row` counts data rows; `spec` counts requests. Index references always resolve, even beyond row width; unresolved names give `UnknownColumn`/`None`, absent resolved cells give `MissingCell`/`Some(index)`. Both beat nullable handling. Only an existing exact empty string becomes nullable `Null`; otherwise Text accepts everything verbatim, while other empty types give `Empty`. Do not mutate or CSV-validate cells.

8. **R33–R35:** Validate the entire numeric spelling before range checks, so an enormous malformed value gets `InvalidInteger`/`InvalidDecimal`. Integers reject `-0`, plus signs and leading zeros; decimals require exactly two fractional digits and reject only negative zero `-0.00`, allowing `-0.01`. Accept both i64 endpoints, including decimal hundredths `-92233720368547758.08` and `92233720368547758.07`, without intermediate overflow. Boolean accepts only `yes`, `1`, `no`, `0`; no trimming or Unicode digits.

9. **R36–R40:** Every included output row has one position per requested spec. Collect evaluates everything, retaining successes and ordering errors by row/spec. FirstPerRow stops that row at its first failure; Stop stops globally but includes the failing row. Failure and unvisited positions remain `None`. Zero specs yield one empty output row per data row under every policy; zero data rows yield no errors, even for unknown names.

10. **R42–R45, R55:** Writer precedence is config → first NUL across all original cells → first original header-width mismatch → first zero-column record → canonical duplicate rejection. A later NUL beats earlier structural errors, including in discarded columns. Scan header first, then rows, with field-local UTF-8 byte offsets. `Some(vec![])` is a real zero-column header. Preserve never rejects duplicates; canonical rejection applies only with a header and Reject policy.

11. **R46–R49:** Preserve retains every original column and row. Canonical with a header selects earliest occurrences for KeepFirst/Reject or latest for KeepLast, then orders distinct names by ascending UTF-8 bytes and projects rows accordingly. Sort data lexicographically by decoded projected field vectors, with proper prefixes first; retain identical rows. Without headers, sort original vectors and preserve column order and differing nonzero widths.

12. **R50–R54:** Quote **if and only if** a field contains configured delimiter/quote/CR/LF, begins or ends with ASCII space/tab, is the first output field and starts with BOM, or is a record’s sole empty field. Double only configured quote bytes; preserve everything else. Apply first-field BOM protection after canonical ordering. Preserve uses configured separators and optional final terminator; Canonical always uses LF and one final LF. No records always produce an empty string; sole empty fields must survive even without a final terminator.
