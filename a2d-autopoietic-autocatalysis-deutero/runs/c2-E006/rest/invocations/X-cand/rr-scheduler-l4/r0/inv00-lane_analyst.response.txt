1. **R1, R39:** Preserve every public type, field, signature, and derive exactly; use one std-only Rust 2024 source file. Do not mutate inputs or retain state between calls. IDs 0 and `u32::MAX` are valid, so neither can serve as an absent-id sentinel.

2. **R2–R11:** Validate everything before simulation: level count → quanta by index → switch cost → job count → rows by input index. Within each row: duplicate id → arrival → initial level → burst count → bursts by position. Finish checking an earlier row before considering any later row; empty jobs still require parameter validation.

3. **R3–R12:** Bounds are inclusive: 1–8 levels, quanta 1–1000, switch cost 0–1000, 0–64 jobs, arrivals 0–1000, and odd burst counts 1–31. Initial level must be strictly below level count. CPU lengths are 1–1000; I/O delays are 0–1000.

4. **R13–R16, R28–R29:** Start at 0 and admit all events through current time before selection. Globally order events by their original `(timestamp, kind, input index)`, even when admitting overdue events together; arrivals precede wakes only at equal timestamps. Append to FIFO queues and select the lowest numbered nonempty queue.

5. **R17–R19, R30–R32:** Remove and lock the selected head before charging a switch. Charge exactly once when its id differs from the remembered dispatch id; the first dispatch is free. Admit events through cost end without replacing the selection. Cost consumes neither quantum nor idle time; same-id dispatches remain free across level changes and zero I/O.

6. **R15, R19–R21, R23:** Execution is uninterrupted despite arrivals or wakes. Use the level and quantum at selection, consume `min(remaining CPU, quantum)`, and emit one unmerged Run starting after cost. Each dispatch gets a fresh quantum; `finished` means the entire job has completed.

7. **R22–R24, R28:** After execution, admit events through and including Run.end before requeuing unfinished CPU work. Demote only when that CPU burst still has work, cap at the last level, and append after admitted events. Burst completion wins when remaining work equals the quantum.

8. **R24–R28:** A nonfinal CPU completion blocks until `Run.end + I/O delay`; its next CPU uses a fresh quantum. At wake, promote from the level of the dispatch that started I/O, saturating at 0. Include the newly generated zero-delay wake in endpoint admission, ordered with all other endpoint events by R28.

9. **R18, R30–R32:** Remember the executed id after every Run, including one that blocks or finishes. Clear it only when positively advancing time while idle; another job already ready after a completion can therefore incur a switch cost. Event admission alone never clears it.

10. **R31–R33, R38:** With no ready job, jump to the earliest pending event and record only a positive idle interval. Include initial idle from 0, merge touching idle intervals, and emit no trailing idle. With valid parameters and no jobs, all vectors are empty and end and both means are 0.

11. **R34–R36:** Emit stats in input order. Completion is the final CPU Run.end; turnaround subtracts arrival; waiting additionally subtracts every CPU length and every I/O delay. Waiting includes the job’s own switch costs and ready-queue delays, including after wakes, but excludes blocked time and time before arrival.

12. **R37–R39:** Compute each mean from the total across all jobs, multiply by 100, then divide with nearest rounding and exact halves upward; never round individual contributions or use floating point. Include every initial level. Convert operands to u64 before time additions, sums, and multiplication; the bounds guarantee exact u64 results.
