1. **R1–R4, R17, R21–R23:** Match the exact public types and signatures; `parse` is associated with `Big`. Keep `Big`’s representation private, implement the required traits, and use exactly the specified `Error` variants and field types. Deliver one std-only Rust 2024 source file in Rust fences, without `main` or inner attributes/docs.

2. **R5–R8:** Only one ASCII `+` at byte 0 is optional. `""` is `Empty`; `"+"` is `SignOnly`; `"-"` is `InvalidDigit { index: 0 }`. Whitespace is never trimmed, and subsequent signs are invalid digits.

3. **R8, R10–R11, R14:** Scan the entire magnitude for invalid bytes before checking separators, leading zeros, or limits. Report the leftmost invalid byte using its original UTF-8 byte offset, including the sign; a non-ASCII character fails at its first byte.

4. **R9–R11, R14:** An underscore needs immediate ASCII-digit neighbors on both sides within the magnitude. After invalid-byte validation succeeds, report the leftmost malformed underscore; it outranks leading-zero and limit errors. Thus `"__"` fails at 0 and `"+_1"` at 1.

5. **R12, R14:** After separator validation, reject a first digit of zero whenever there are multiple digits, ignoring underscores. `"0_0"` is `LeadingZero { index: 0 }`; `"+00"` reports index 1, even with `max_digits=0`.

6. **R13–R15:** Check the limit last, counting only digits. Report the original byte offset of the first excess digit and preserve the supplied limit. Zero consumes one digit; `max_digits=0` rejects every valid magnitude. Support `usize::MAX` without overflowing while computing the excess position.

7. **R2, R15–R16, R24:** Use arbitrary-precision numerical values with one canonical zero. Neither machine-integer bounds nor an implicit cap is allowed. Equality ignores spelling and parse limits; clones preserve equality, and arithmetic results retain neither spelling nor limits.

8. **R17–R18, R20:** Format decimal magnitude without a sign or unnecessary zeros, then pad to at least `min_digits`; never truncate. Zero emits `"0"` even at width 0. Padded output may intentionally violate parsing’s leading-zero rule.

9. **R19:** Group only after padding, counting from the right. `group=0` disables separators; `group=1` separates every digit. Avoid edge underscores, including exact multiples; groups larger than the digit count emit none. Handle `group=usize::MAX` without arithmetic overflow.

10. **R21:** Compare numerical magnitude, including zero and equality, independently of formatting or representation. Lexicographic decimal comparison alone is insufficient: 9 is less than 10.

11. **R15, R22, R24:** Addition must propagate carries across the entire value, including long runs of nines, and may exceed either operand’s parse limit. Adding zero and adding a value to itself must work without mutating operands.

12. **R15, R23–R24:** Subtraction returns `Underflow` exactly when the left value is smaller. Otherwise propagate borrows across arbitrary distances, remove redundant leading zeros, and produce canonical zero for equality. Successful and failed operations both leave operands unchanged.
