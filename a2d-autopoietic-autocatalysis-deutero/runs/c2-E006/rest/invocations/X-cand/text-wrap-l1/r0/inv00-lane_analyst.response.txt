1. **R1–R2:** Deliver one Rust source file in `rust` fences, compiling with `rustc --edition 2024`, using only `std`. Match the public API exactly; `WrapError` needs all four specified derives and the exact variant fields.

2. **R3–R5:** Validate width first, even for empty or invalid input: zero yields `WidthZero`; any value above 256, including `usize::MAX`, yields `WidthTooLarge`. Widths 1 and 256 are valid.

3. **R4:** Validate the entire original input before returning success. Report the earliest forbidden byte with its original zero-based byte index; for non-ASCII UTF-8, report its first forbidden encoded byte, not a character index.

4. **R4–R6:** Only space, tab, LF, and CR separate words. Collapse any mixture or repetition; ignore leading/trailing separators. Empty or separator-only input returns an empty vector. Other whitespace, including vertical tab and form feed, is invalid.

5. **R3, R6–R7, R16:** Preserve punctuation, backslashes, and existing hyphens literally. Add no hyphens, escapes, or indentation. Width includes every output byte, including inserted spaces and literal hyphens.

6. **R8–R10, R12:** Reclassify the *remaining suffix* after every consumption. A suffix of length exactly `width` belongs to the whole-suffix rules; splitting rules apply only when its length is strictly greater than `width`.

7. **R8–R9:** A suffix of length at most width must remain whole. Append it with exactly one space if the combined length fits, including exact equality; otherwise emit the current line and retry without consuming any suffix bytes.

8. **R10, R14:** On an empty line, a suffix longer than width emits exactly its first `width` bytes immediately. Repeat as needed; an exactly divisible word produces no trailing empty line.

9. **R11, R14:** Emit a full current line before processing another word. Avoid unsigned underflow in `width - current_length - 1`; in particular, a full line must never reach that subtraction.

10. **R11–R13:** For a long suffix and nonempty line, `available >= 2` consumes exactly `available` suffix bytes after one space and emits the full line. At `available` zero or one, emit the existing line and consume nothing; leave the single available column unused.

11. **R7, R15:** A short remainder of a split word stays on the current line and can share it with the next word. Preserve input order and never revisit emitted lines or rebalance earlier breaks.

12. **R14–R16:** At end of input, emit only a nonempty current line. Every returned line must have length at most width, contain no newline or edge spaces, and preserve all input nonseparator bytes exactly once and in order.
