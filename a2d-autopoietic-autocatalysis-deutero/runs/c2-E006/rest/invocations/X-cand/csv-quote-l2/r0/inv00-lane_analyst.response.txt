1. **R1, R29:** Supply one std-only source file compatible with `rustc --edition 2024`, inside Rust fences. Implement every exact public signature, variant, field and required derive; omit inner attributes and inner documentation. Callers must be able to construct `Config` and `Table` directly.

2. **R3–R4, R10:** Ignore exactly one leading U+FEFF, but include its three UTF-8 bytes in absolute error offsets. Later BOMs are data. Error record indices count only consumed terminators outside quotes; CRLF counts once and quoted newlines count zero times.

3. **R5–R6, R16:** Empty input and BOM-only input produce zero records. A blank terminated record contains one empty field; consecutive terminators each produce a record, without an extra record after the final terminator. Preserve leading, consecutive and trailing empty fields. `,` yields two empty fields; `""` yields one empty field and one record.

4. **R8–R9, R12, R16:** Quotes may open only at field start, without preceding whitespace. Inside quotes, consecutive quote bytes always decode to one literal quote—even at EOF, where that escape leaves the field unclosed. A single closing quote at EOF is valid; an unclosed field reports its opening quote’s offset.

5. **R7, R11, R13–R14, R27:** Scan left to right and return no partial result. At the current byte, check NUL first; outside quotes, validate CR before state-specific checks. Thus bare CR after a closing quote is `BareCr`, while spaces/tabs there are `TrailingByte`. An earlier bare CR wins over a subsequent NUL. Check `UnclosedQuote` only after scanning all bytes.

6. **R2, R10, R15–R18:** Preserve Unicode, whitespace, case and quoted newline bytes exactly, including bare CR inside quotes. NUL remains forbidden inside quotes. Do not trim, normalize, process backslashes/comments, skip blank records or decode escapes twice. Preserve record/column order, impose no undocumented size limits, and retain no state between `parse_csv` calls.

7. **R19–R20:** Validate delimiter range first, quote range second, equality third; equality reports `ConfigPart::Quote`. Both ranges include `0x21` and `0x7e`; letters and punctuation are valid. Configuration errors precede input inspection. Configured bytes replace comma/double quote throughout the grammar; the original punctuation becomes ordinary data. `parse_csv` always uses its fixed dialect.

8. **R21, R29:** `new` validates configuration immediately. Before finish, every `feed`, including malformed text and empty chunks, merely appends verbatim and returns `Ok`. Parse the concatenation, allowing BOMs, CRLF, quote escapes and records to cross chunk boundaries; offsets never restart per chunk. `read_csv` must match new/feed/finish.

9. **R22–R23:** Cache both successful and failed finish results; subsequent finishes return equal clones. Any feed after finish returns `ReaderFinished`, including an empty feed, without altering the cache. Reset works before finish or after either outcome, clearing input/cache while retaining the original configuration.

10. **R24, R26–R27:** Without headers, retain every record and permit differing widths. With headers, consume exactly the first parsed record; absent records mean `None`, whereas a blank first record is a one-empty-name header. Validate the entire input lexically before header checks, then duplicates before widths. Report the first wrong-width data record using its original record index, starting at 1; never pad or truncate.

11. **R25, R27:** Compare decoded header names exactly, case-sensitively and without trimming; empty names are valid. Reject the earliest second occurrence by column order, reporting that name, its earliest column and the current column. KeepFirst/KeepLast retain every header column and row cell; they only suppress duplicate rejection and control lookup.

12. **R24, R28–R29:** Always copy `Config.duplicates` into the table. Lookup returns `None` for absent headers/names, the greatest matching index for KeepLast, and the least for KeepFirst or Reject—even in manually constructed tables containing duplicates under Reject. Lookup must not validate row widths.
