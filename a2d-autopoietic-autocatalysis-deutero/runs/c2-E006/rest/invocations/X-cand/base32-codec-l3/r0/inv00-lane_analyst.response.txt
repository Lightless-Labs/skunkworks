1. **R1–R2:** Deliver one edition-2024, std-only Rust source file in a `rust` fence, with no inner attributes/doc comments. Preserve both public signatures and every error variant, field type, and listed derive exactly; appended tests must compile.

2. **R3–R5, R28:** Treat input as a byte bitstream, preserving leading zero bytes. Use the exact data alphabet, consume bits MSB-first, right-zero-fill only the last partial symbol, and emit neither padding, separators, nor an extra empty group. Support every byte value and repeated groups.

3. **R6–R8:** Empty encoding is `""` unchecked and `"0"` checked. Checked encoding appends exactly one symbol from the distinct 37-symbol check alphabet; compute its value over emitted five-bit data values, including the zero-filled final value.

4. **R8, R23, R28:** Keep the remainder reduced modulo 37 after each symbol; do not accumulate the whole encoded number or allow bit-buffer, length, or capacity arithmetic to overflow on long inputs. Lowercase, aliases, and hyphens must not change the remainder.

5. **R9, R12–R14:** Skip only ASCII `-`, wherever it occurs. Preserve original UTF-8 byte offsets; whitespace and non-ASCII are invalid, and non-ASCII fails on its first offending byte. Report the original invalid byte, without case-folding it.

6. **R10–R11, R26:** Accept ASCII case-folding and only the stated aliases: `I/i/L/l→1`, `O/o→0`. `U/u`, `*`, `~`, `$`, `=` are check-only values 36, 32, 33, 34, 35 respectively; `=` never introduces padding.

7. **R14–R15, R30:** Reserve the last non-hyphen **byte** as check before validating roles. No such byte in checked mode means `MissingCheck { offset: input.len() }`. One significant byte is check-only in checked mode; unchecked, a recognized data byte fails length, while an unrecognized byte fails lexical validation first.

8. **R16–R18:** Enforce separate validation passes in this exact order: missing check → all data lexical validation → check lexical validation → length → trailing bits → mismatch. The earliest invalid data byte wins even if a later check is invalid; an invalid check beats length errors.

9. **R19, R25:** Count only data symbols after hyphen removal and check reservation. Legal counts modulo eight are exactly `0,2,4,5,7`, including zero and repeated complete groups; other residues produce `InvalidLength` at the full original `input.len()`.

10. **R20–R22:** Decode normalized values MSB-first, excluding hyphens and check. Final unused low bits must be zero: residues `2/4/5/7` require `2/4/1/3` zero bits. Failure points to the original last data-symbol offset and beats any mismatch.

11. **R24–R25:** Compare numerical normalized check values, returning `CheckMismatch` at the original check offset with numerical `expected` and `found`. Empty unchecked data, including only hyphens, succeeds; empty checked data succeeds with `0`, `O`, or `o`, and other valid check values mismatch against zero.

12. **R27–R29:** Errors expose no partial bytes; calls share no state and leave input untouched. Successful decode/re-encode with the same flag must canonicalize aliases, lowercase, and separators into uppercase data plus the canonical check symbol when checked.
