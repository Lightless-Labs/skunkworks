1. **R1:** Match every public name, variant, field and signature exactly; derive `Debug, Clone, PartialEq, Eq` on all three enums. `Edit` remains public even though the function returns only text.

2. **R2–R5:** `""` has zero lines; `"\n"` has one empty line; `"a\n\n"` has two lines. Remove only LF terminators. Exactly 128 lines per side is allowed; `TooLarge` reports both actual counts, without truncation.

3. **R3–R7:** Validate strictly in this order: context; Old CR; New CR; Old final LF; New final LF; line counts. Thus New CR beats Old missing LF. Identical inputs must undergo all validation.

4. **R3, R4, R6:** Empty inputs need no final LF; every nonempty input does. Any CR is forbidden, even before LF; report its first UTF-8 **byte** offset on the winning side. Context 0 and 8 are valid; every larger `usize`, including its maximum, returns `ContextTooLarge` before arithmetic such as `2*context`.

5. **R8, R12:** Compare and preserve complete line contents verbatim: whitespace, case, Unicode, NUL and empty lines. Do not trim, normalize Unicode, or interpret NUL as termination.

6. **R9–R10:** Build the LCS table for suffixes, with exhausted suffixes valued zero. Equal current lines always produce Keep, regardless of other optimal scripts; otherwise compare `L(i+1,j)` against `L(i,j+1)`, deleting for greater and inserting for smaller.

7. **R11–R12:** On unequal-line ties, use the parity of the current original indices `i+j`: even means Delete, odd means Insert. Keep advances both indices; Delete only Old; Insert only New. At exhaustion, emit every remaining row with its original index.

8. **R13–R15:** After successful validation, no changes means exactly `""`. Any change requires exactly `"--- before\n+++ after\n"`. A change group is a maximal consecutive run of Inserts/Deletes; even a Delete followed by Insert has no intervening boundary.

9. **R16, R18:** Merge neighboring groups when their intervening Keep count is **at most** `2*context`, including equality, and continue transitively. Context zero merges adjacent changed rows but never groups separated by a Keep.

10. **R17–R19:** Extend each merged group by up to `context` immediately adjacent Keeps on each side, bounded by script edges. Count Keeps rather than edits; emit selected rows once, in script order, with no unselected Keeps.

11. **R20–R22:** Count Keep/Delete toward Old and Keep/Insert toward New. For each side independently, start is consumed-before-hunk plus one when that side’s count is positive, otherwise consumed-before-hunk itself. Pure insertions/deletions can therefore have start 0; always print both counts, including 0 and 1, in the exact header format.

12. **R23–R25:** Prefix every body row with exactly space, `-`, or `+`, including empty lines, then append LF. Preserve payload characters; add no separators, timestamps, escaping or no-newline markers. Every output row ends in LF; inputs remain unchanged and errors expose no partial diff.
