1. **R1–R2:** Deliver one std-only Rust source file in `rust` fences, compatible with edition 2024. Match the public API and error fields exactly, derive all four required traits, use no inner attributes/comments, and require no `main`.

2. **R3–R4:** Preserve literals byte for byte; do not encode literal Unicode, `%`, whitespace, or newlines. Empty input yields `Ok("")`. Every error position is a template UTF-8 **byte** offset, not a character index.

3. **R5, R16:** Validate the whole template before any binding lookup or expansion. The first syntax error in the specified scan order wins; later syntax errors override any earlier prospective value issue. Arbitrary scalar values cannot cause errors.

4. **R6:** Outside expressions, `}` immediately produces `UnexpectedClose`. For `{`, first seek the next `}`; if absent, report `Unclosed` at the opening brace even when additional `{` characters follow.

5. **R7:** If a closing brace exists, the first inner `{` produces `NestedOpen` before operator, empty-content, name, or duplicate checks—even if an earlier content byte would otherwise be invalid. Braces have no escape syntax.

6. **R8–R9, R11:** Recognize an operator only at the first content byte, and recognize at most one. All seven listed operators are unsupported, so `{+}` reports `UnsupportedOperator`, not `EmptyExpression`. Other punctuation follows name validation.

7. **R9, R11:** `{}` reports `EmptyExpression` at `}`. Preserve comma-created empty entries and validate specifiers left to right: `{,a}` reports an empty entry just after `{`, `{a,}` at `}`, while `{1,}` reports the earlier `InvalidName`.

8. **R10:** Enforce the ASCII name grammar, including its stricter first byte. Do not trim whitespace or accept modifiers. Report the first offending byte; for a non-ASCII character, report its first UTF-8 byte.

9. **R11:** Validate each complete name before checking whether it duplicates an earlier name in that expression. Report duplicates at the repeated specifier’s start. Equality is case sensitive, and duplicate tracking resets between expressions.

10. **R4, R12:** Match binding names exactly without validating them, including unused bindings. For repeated binding names, the last entry wins even when empty. Missing variables contribute neither a field nor a separator.

11. **R13–R14:** Encode value UTF-8 bytes using only the stated ASCII pass-through set and uppercase `%HH`. Preserve existing valid triplets with uppercase hex, without decoding; scan greedily. Invalid/incomplete `%` becomes `%25`, then remaining bytes are processed normally.

12. **R15–R16:** Join present fields with commas, counting present empty values as fields: missing-plus-empty yields `""`, while two present empties yield `","`. Add no prefix. Malformed inputs must return errors without panicking; calls must not mutate inputs or share state.
