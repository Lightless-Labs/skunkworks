1. **R1–R2:** Deliver one std-only source file compiling with `rustc --edition 2024`, inside a single Rust fence, with no inner attributes or inner doc comments. Match every public name, signature, field, variant, and requested derive exactly; choose private stream fields.

3. **R6–R8, R41, R43:** Encoder `push` emits only whole five-byte blocks, including blocks completed from earlier buffered input, retaining zero to four bytes. Process bits most significant first, support arbitrary binary bytes, and make concatenated output independent of chunk boundaries.

6. **R15–R16, R37–R38, R44–R45:** Decoder `push` immediately emits every completed byte and retains fewer than eight unresolved bits; padding emits nothing. 7. **R17–R18, R23, R41–R43:** Scan UTF-8 bytes left to right, stopping at the first failing byte without a whole-string prepass. Offsets count absolute original bytes across successful calls, including lowercase and padding; non-ASCII fails at its first UTF-8 byte. Preserve positions and bounded pending state across long streams without narrow-counter truncation or growing-bit-accumulator overflow.

8. **R19–R20, R39:** Every failed call rolls back its entire state and returns no partial output, even after a valid prefix within that call. 9. **R21–R26, R30, R42:** At each byte, apply lexical recognition, then strict lowercase checking, then padding placement. Thus invalid input after padding gives `InvalidByte`; recognized lowercase after padding gives `NonCanonical` in strict mode and `Padding` otherwise. Required mode allows the first `=` only after data residues 2/4/5/7 modulo eight, requiring exactly 6/4/3/1 pads; residue zero, including empty input, rejects it immediately, as do residues 1/3/6. Excess padding fails at the first excess byte; incomplete data or padding at a push boundary is allowed.

11. **R28, R33–R36, R39:** Finish checks data length, then padding completeness, then unused bits. Illegal data residues 1/3/6 produce `InvalidLength` at total consumed bytes. 12. **R37–R39, R41:** Finish requires zero unused low bits: 2/4/1/3 bits for data residues 2/4/5/7 respectively, and none for zero. Report `TrailingBits` at the last data symbol’s absolute offset, even when padding follows it.
