1. **R1–R2:** Deliver one Rust source file in a `rust` fence, compiling under edition 2024 with only `std`. Use the exact public names, signatures, variants, field types, and derives; no inner attributes or inner doc comments.

2. **R3–R5, R24:** Use exactly the selected alphabet’s value mapping, uppercase only. Shared characters can have different values between alphabets; never autodetect, blend alphabets, or normalize input. Choices apply independently per call.

3. **R6–R8, R19:** Process bits most significant first across byte boundaries. Zero-fill only the final partial five-bit symbol on its right. Required encoding adds `=` only to reach a multiple of eight symbols; Omitted changes only padding emission.

4. **R9, R16–R17:** Empty input succeeds in both directions and modes. Complete data blocks require no padding. An all-padding string is invalid, as is padding appended after a complete data block.

5. **R10–R12:** Finish lexical validation before checking anything structural. Scan original UTF-8 bytes left to right; the first byte outside the selected alphabet and `=` wins, even if an earlier byte already implies a padding error. Non-ASCII fails on its first UTF-8 byte, carrying that actual byte.

6. **R10, R13–R14:** After lexical success, check padding mode/placement before length. Omitted rejects the first `=` at `p`; Required rejects the first alphabet byte after the first `=` at that alphabet byte’s offset.

7. **R10, R15:** After placement succeeds, set data length `d=p`, where absent padding means `p=n`. Only residues `0,2,4,5,7` modulo eight are legal. Otherwise return `InvalidLength { offset: n }`, before checking padding shape or trailing bits.

8. **R16–R17:** Required demands exactly `0,6,4,3,1` padding bytes for data residues `0,2,4,5,7`, respectively, and total length divisible by eight. Any shape failure reports `Padding { offset: p }`; missing padding therefore reports the end offset `n`.

9. **R18:** Omitted accepts every legal data-length residue without requiring total length divisible by eight. It performs no padding-shape check after the earlier pass has ruled out all `=` bytes.

10. **R19–R21:** Padding contributes no bits. After all earlier passes succeed, require the final data symbol’s low `2,4,1,3` bits to be zero for residues `2,4,5,7`; residue zero has no unused bits. Failure is `TrailingBits { offset: d-1 }`.

11. **R11–R12, R15, R17, R21:** Offsets always count original UTF-8 bytes, never characters, decoded bytes, or normalized positions. Preserve each error’s specified location: offending byte, `n`, `p`, or the final data byte, respectively.

12. **R22–R24:** Handle arbitrary binary values and repeated blocks without fixed-size assumptions or overflowing a growing bit accumulator or length calculation. Errors expose no partial output; calls share no mutable decoding state. Every successful decode must re-encode to the exact original string under the same options.
