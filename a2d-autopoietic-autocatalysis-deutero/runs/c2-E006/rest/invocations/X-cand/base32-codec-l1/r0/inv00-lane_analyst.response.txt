1. **R1–R2:** Deliver one edition-2024 Rust source file, std only, inside one `rust` fence. Preserve the exact public signatures, enum variants, field types, and four derives; add no extra public operations, inner attributes, or inner doc comments.

2. **R3–R5:** Alphabet values follow the stated order. Read bytes most significant bit first; right-pad only a nonempty final five-bit group with zeros. Never emit an extra symbol when the bits divide evenly.

3. **R6–R7:** Padding is mandatory for incomplete blocks. Input lengths 1–5 bytes produce respectively 2, 4, 5, 7, 8 data symbols and 6, 4, 3, 1, 0 equals signs. Empty input produces nothing.

4. **R8–R10:** Complete lexical validation before any structural validation. The first invalid byte anywhere wins, even after misplaced padding. Offsets count original bytes; for non-ASCII characters, report their first offending UTF-8 byte, not a character index or code point.

5. **R11:** After lexical success, find the first `=` and reject the first subsequent alphabet byte with `Padding` at that subsequent byte. Repeated `=` alone does not fail this pass.

6. **R12:** Data length is the first `=` offset, or the entire byte length without padding. Reject residues 1, 3, and 6 with `InvalidLength` at the **total input length**, regardless of padding count.

7. **R13–R14:** Legal data residues 0, 2, 4, 5, 7 require exactly 0, 6, 4, 3, 1 padding bytes respectively, plus total length divisible by eight. Unpadded partial blocks are invalid; complete data blocks cannot have padding.

8. **R7, R11–R14:** Only the empty string represents zero bytes successfully. Every nonempty all-`=` string reaches padding shape and returns `Padding { offset: 0 }`, even when its length is divisible by eight.

9. **R8, R14, R17:** Error precedence is lexical → placement → data length → shape → trailing bits. For example, `"A="` gives `InvalidLength { offset: 2 }`; `"AB"` gives `Padding { offset: 2 }`; `"AB======"` gives `TrailingBits { offset: 1 }`.

10. **R15–R17:** Padding supplies no bits. After all earlier passes succeed, check the final symbol’s low 2, 4, 1, or 3 bits for residues 2, 4, 5, or 7 respectively. Any nonzero unused bit reports offset `d-1`; residue zero requires no check, including empty input.

11. **R18:** Errors expose no partial decoded bytes. Calls must not depend on prior calls, and neither encoding nor decoding may modify its input.

12. **R4–R6, R15, R19:** Handle every byte value and arbitrarily many blocks without fixed-size limits or overflowing accumulated bits or length arithmetic. Preserve leading zero bytes and emit only complete decoded bytes. Every accepted encoded string must round-trip through decoding and encoding exactly, including its padding.
