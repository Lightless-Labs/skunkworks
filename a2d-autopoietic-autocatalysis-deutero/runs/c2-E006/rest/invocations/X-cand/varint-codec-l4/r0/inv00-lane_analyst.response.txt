1. **R1–R3:** Deliver one std-only source file compiling with `rustc --edition 2024`, inside only a Rust fence, without inner attributes or inner doc comments. Preserve the exact public types, fields, function signatures, derives, and Error variants and members; add no Error variants.

2. **R4, R8–R10, R23, R36:** Validate `max_depth <= 32` first, then `start <= input.len()`. An excessive start gives `StartOutOfBounds`; equality gives header `Truncated`. Validate root header integrity, canonicality, and length bounds before any fields. Decode exactly one frame, return its absolute end, and ignore trailing input; `[0]` is an empty frame.

3. **R5–R7, R19, R31–R33:** Apply identical varint rules to every header, key, value, and length, including skipped fields. At byte ten, payload >1 or continuation means `Overflow` at that byte, without reading byte eleven. Missing bytes mean `Truncated { offset: container_end, start: varint_start }`; otherwise a multibyte encoding is noncanonical exactly when its final payload is zero. Integrity precedes canonicality; canonicality precedes semantic use.

4. **R7, R9, R20–R21, R38:** Root headers read within input; every body varint and payload stays within its own body boundary, regardless of trailing bytes. Compare declared u64 lengths with remaining bytes before narrowing or adding. Root length errors use header start; wire-2/3 bounds errors use length-varint start; fixed-width shortages use key start and length 8 or 4. Decoder offsets remain absolute throughout descendants.

5. **R11–R15, R23, R40:** For each field, check full key varint integrity → key canonicality → tag validity → wire validity → order → duplicate rule, before payload processing. Compute tag from the full u64 key; require 1..=255 before narrowing. Supported wires are exactly 0, 1, 2, 3, 5. Invalid tags beat invalid wires; invalid wires beat order errors; duplicate Nested fields beat length or depth errors.

6. **R14–R15, R17, R25, R30, R38:** Ordering uses every field, including skipped ones, and the immediately preceding field’s tag and wire. Tags must be nondecreasing; equality is legal only for two wire-2 fields (two Bytes variants when encoding). Each child starts fresh ordering state, and child fields never alter parent state.

7. **R16–R18, R28, R30, R39:** Retain tags 1..=15 with wires 0, 2, and 3 as UInt, Bytes, and Nested respectively; no tag-specific schema applies. Skip known wires 1/5 and all supported wires for tags 16..=255. Merge repeated retained wire-2 fragments into one Bytes at the first fragment’s position, including empty fragments; repeated unknown bytes produce nothing. Empty and skipped-only bodies succeed.

8. **R17, R19–R23, R43:** Skipping still requires full validation. Wire 0 validates its payload varint with its own start; wires 1/5 consume exactly 8/4 opaque bytes; wires 2/3 validate length integrity, canonicality, then bounds. Raw byte data and fixed-width payload contents are never parsed, even when they resemble malformed varints.

9. **R34–R39, R43:** Wire 3 contains a length followed directly by child **body**, without another frame header. Root depth is 0; child depth is parent depth +1, and equality with `max_depth` is allowed. Even empty or unknown children require depth checks: length integrity, canonicality, and bounds precede depth, which precedes child content. Depth errors use nested key start; unknown children are recursively validated before discarding, while known children retain even empty Messages.

10. **R24–R27, R40–R43:** Encoder accepts only tags 1..=15 and validates supplied order without sorting. At each field, validate tag, order, and duplicates before recursion; check child depth before child fields, and finish child validation before later siblings. Encoder offsets are local field indices: depth errors identify the parent field index, and child errors propagate unchanged. Invalid parent tags or ordering beat depth errors.

11. **R5–R6, R26–R27, R32, R43:** Support UInt’s entire u64 range, including zero and maximum; a valid ten-byte varint ending in payload 1 is canonical. Encode all varints minimally, use wires 0/2/3, prefix nested body lengths and the root body length, preserve separate repeated Bytes fragments, and never mutate input. Consequently, decoding an encoding may merge Bytes fields and need not reproduce the original field vector exactly.

12. **R2–R3, R23, R29, R36–R37:** Match exact error variants and member values, return no partial Message, remain deterministic, and avoid panics or arithmetic wrapping on arbitrary input apart from allocation exhaustion. Hidden cases include combined failures, depth limits 0/32/33, nonzero starts, maximum varints and lengths, empty fragments and children, malformed unknown descendants, and payloads that could otherwise consume bytes beyond their containing body.
