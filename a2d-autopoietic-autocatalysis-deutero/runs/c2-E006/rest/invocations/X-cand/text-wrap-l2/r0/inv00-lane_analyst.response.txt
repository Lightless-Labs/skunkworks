1. **R1–R2:** Submit one std-only Rust source file in a `rust` fence, compiling with edition 2024. Preserve the exact public API, field types, variant payloads, and required derives; add no extra callable API.

2. **R3–R5:** Error precedence is strictly WidthZero → WidthTooLarge → FirstIndentTooWide → RestIndentTooWide → first InvalidControl. Validate everything even for empty input; an earlier error wins regardless of later failures.

3. **R3–R4, R11:** Width 256 is valid; 257 is not. Zero indents are valid, but either indent equal to width fails. Width 1 with zero indents is valid. Reject oversized values, including `usize::MAX`, before layout arithmetic.

4. **R5–R6:** Scan original input using `char::is_control()`, exempting only tab, CR, and LF. Return the earliest offending scalar’s original UTF-8 byte offset, not its character index or normalized offset. Other Unicode scalars pass validation.

5. **R6, R8:** Normalize CRLF to one LF before converting remaining CRs to LF. Detect paragraph boundaries afterward: CRLF alone is one soft separator, while CRLF followed by CR becomes a two-LF boundary.

6. **R7, R10, R17:** Only ASCII space, tab, LF, CR, and NBSP separate words. Preserve all other scalars literally, including combining marks, emoji, EM SPACE, and soft hyphen; each counts as one column. Do not insert hyphens.

7. **R8–R9:** Each maximal adjacent LF run of length `n >= 2` contributes exactly `n−1` empty strings, including at input edges. Spaces, tabs, or NBSP between LFs break adjacency; do not trim or collapse separators before detecting boundaries.

8. **R9–R11:** Empty/all-separator segments yield no content lines, but their boundary empty strings remain. Empty input yields `[]`; a single LF also yields no lines. Every segment restarts first-indent status, and boundary strings contain no indentation.

9. **R10–R12, R17:** Collapse separators within each segment into single spaces between words and discard leading/trailing separators. Indentation is ASCII spaces; capacity excludes indentation, while the total width includes it. Output has no embedded CR/LF or trailing spaces.

10. **R12–R13:** First compare the current suffix’s scalar length with the current line’s entire capacity `C`. If length `<= C`, append it whole only if it fits with any required separating space; otherwise emit and retry without consuming it. Recompute `C` after every emitted line.

11. **R14–R15:** A suffix longer than `C` consumes exactly `C` scalars on an empty line. On a nonempty line, consume `C − content_length − 1` scalars only if that value is at least two; otherwise emit without consuming. Handle full lines before subtraction to avoid unsigned underflow.

12. **R13–R16:** Retry remainders before advancing to the next word; changed indentation can change whether they split. Emit full lines immediately, allow a short split tail to share with the next word, and emit only nonempty content at paragraph end—never an extra line for exact divisibility.
