R2. new first validates retry_base>0 and retry_cap>=retry_base, else Config. aging_ms may be zero. Empty job input is valid.
R3. Validate jobs in input order, with per-job precedence BadId(index), BadPriority(index), BadAttempts(index), Duplicate(index). Indices are zero-based; Duplicate identifies the later job.
R4. IDs contain 1..=16 ASCII lowercase-letter/digit/hyphen bytes. Priority is 0..=9; max_attempts is 1..=32, counting the initial attempt.
R5. After all local job validation succeeds, validate dependencies in job order and then list order. R7. All failed calls are atomic: no state, time, attempt counters, or ordering changes.
R8. begin_cycle, next_ready and complete check now less than last successful timed call first and return TimeReversed. Equal timestamps are allowed. A successful timed call, including Ok(None), records now.
R9. Before any cycle, next_ready and complete return NoCycle after the time check. status returns NoCycle before looking up its ID.
R10. begin_cycle is Busy when any job in the previous cycle is Waiting or Running; this check follows the time check.
R11. begin_cycle otherwise resets every job to Waiting { ready_at: now } and attempts to zero. It also clears all previous success/failure/blocked results.
R12. An empty cycle is immediately terminal. begin_cycle may immediately begin another empty cycle.
R13. status after a cycle begins uses exact ID lookup; unknown gives Unknown. It returns an owned State snapshot and changes nothing.
R14. next_ready can dispatch a Waiting job only when ready_at<=now and all dependencies have Succeeded in this same cycle.
R15. Waiting includes jobs held by unsatisfied dependencies. Running jobs never dispatch again until completed.
R16. Effective priority is base priority if aging_ms=0, else min(9, base priority + floor((now-ready_at)/aging_ms)), with overflow-safe arithmetic.
R17. Aging starts at the job waiting-state ready_at, even while dependencies prevent dispatch. After a retry, aging instead starts at the retry ready_at.
R18. Pick highest effective priority; ties use original job input order, independent of dependency-list order or ID spelling.
R19. On dispatch increment that job attempt count, set Running { attempt: count }, and return Ticket with ID and count.
R20. No eligible job yields Ok(None); next_ready never advances time beyond its argument and never auto-completes work.
R21. Any number of independent jobs may be Running simultaneously. There is no worker-capacity constraint in this level.
R22. complete checks time, then NoCycle, then exact lookup (Unknown), then state (NotRunning unless Running). Do not validate ID syntax here.
R23. complete(success=true) sets Succeeded, regardless of attempt number.
R24. complete(success=false) when attempt count equals max_attempts sets Failed.
R25. Otherwise a failed completion schedules Waiting { ready_at: now + delay }; addition saturates at u64::MAX.
R26. Delay after failed attempt a is min(retry_cap, retry_base * 2^(a-1)), computed mathematically without overflow.
R27. Failed attempts do not satisfy dependencies. Retrying a parent must succeed before its dependents become dispatchable.
R28. After terminal failure, repeatedly mark any Waiting job Blocked if any dependency is Failed or Blocked. Propagate transitively through the entire graph, including jobs with future ready_at.
R29. Propagation does not increment blocked jobs attempts, and does not block unrelated jobs.
R30. Failed and Blocked are terminal within a cycle; only begin_cycle can reset them. Succeeded is also terminal.

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Job {
    pub id: String,
    pub priority: u8,
    pub dependencies: Vec<String>,
    pub max_attempts: u8,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum State {
    Waiting { ready_at: u64 },
    Running { attempt: u8 },
    Succeeded,
    Failed,
    Blocked,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Ticket {
    pub id: String,
    pub attempt: u8,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Error {
    Config,
    BadId(usize),
    BadPriority(usize),
    BadAttempts(usize),
    Duplicate(usize),
    DuplicateDependency(usize, usize),
    MissingDependency(usize, usize),
    Cycle,
    TimeReversed,
    Busy,
    NoCycle,
    Unknown,
    NotRunning,
}

struct Entry {
    job: Job,
    dependencies: Vec<usize>,
    state: State,
    attempts: u8,
}

pub struct Runner {
    entries: Vec<Entry>,
    aging_ms: u64,
    retry_base: u64,
    retry_cap: u64,
    last_time: u64,
    cycle_started: bool,
}

impl Runner {
    pub fn new(
        jobs: Vec<Job>,
        aging_ms: u64,
        retry_base: u64,
        retry_cap: u64,
    ) -> Result<Self, Error> {
        if retry_base == 0 || retry_cap < retry_base {
            return Err(Error::Config);
        }

        let mut ids = std::collections::HashMap::new();
        for (i, job) in jobs.iter().enumerate() {
            if job.id.is_empty()
                || job.id.len() > 16
                || !job
                    .id
                    .bytes()
                    .all(|b| b.is_ascii_lowercase() || b.is_ascii_digit() || b == b'-')
            {
                return Err(Error::BadId(i));
            }
            if job.priority > 9 {
                return Err(Error::BadPriority(i));
            }
            if !(1..=32).contains(&job.max_attempts) {
                return Err(Error::BadAttempts(i));
            }
            if ids.insert(job.id.as_str(), i).is_some() {
                return Err(Error::Duplicate(i));
            }
        }

        let mut all_deps = Vec::with_capacity(jobs.len());
        for (i, job) in jobs.iter().enumerate() {
            let mut seen = std::collections::HashSet::new();
            let mut deps = Vec::with_capacity(job.dependencies.len());
            for (j, dep) in job.dependencies.iter().enumerate() {
                if !seen.insert(dep.as_str()) {
                    return Err(Error::DuplicateDependency(i, j));
                }
                match ids.get(dep.as_str()) {
                    Some(&idx) => deps.push(idx),
                    None => return Err(Error::MissingDependency(i, j)),
                }
            }
            all_deps.push(deps);
        }

        let mut indegree = vec![0usize; jobs.len()];
        let mut dependents = vec![Vec::new(); jobs.len()];
        for (i, deps) in all_deps.iter().enumerate() {
            indegree[i] = deps.len();
            for &dep in deps {
                dependents[dep].push(i);
            }
        }
        let mut queue = std::collections::VecDeque::new();
        for (i, &d) in indegree.iter().enumerate() {
            if d == 0 {
                queue.push_back(i);
            }
        }
        let mut visited = 0usize;
        while let Some(n) = queue.pop_front() {
            visited += 1;
            for &child in &dependents[n] {
                indegree[child] -= 1;
                if indegree[child] == 0 {
                    queue.push_back(child);
                }
            }
        }
        if visited != jobs.len() {
            return Err(Error::Cycle);
        }

        let entries = jobs
            .into_iter()
            .zip(all_deps)
            .map(|(job, dependencies)| Entry {
                job,
                dependencies,
                state: State::Waiting { ready_at: 0 },
                attempts: 0,
            })
            .collect();

        Ok(Self {
            entries,
            aging_ms,
            retry_base,
            retry_cap,
            last_time: 0,
            cycle_started: false,
        })
    }

    pub fn begin_cycle(&mut self, now: u64) -> Result<(), Error> {
        if now < self.last_time {
            return Err(Error::TimeReversed);
        }
        if self.cycle_started
            && self.entries.iter().any(|e| {
                matches!(e.state, State::Waiting { .. } | State::Running { .. })
            })
        {
            return Err(Error::Busy);
        }
        for entry in &mut self.entries {
            entry.state = State::Waiting { ready_at: now };
            entry.attempts = 0;
        }
        self.cycle_started = true;
        self.last_time = now;
        Ok(())
    }

    pub fn next_ready(&mut self, now: u64) -> Result<Option<Ticket>, Error> {
        if now < self.last_time {
            return Err(Error::TimeReversed);
        }
        if !self.cycle_started {
            return Err(Error::NoCycle);
        }

        let mut best: Option<(usize, u8)> = None;
        for (i, entry) in self.entries.iter().enumerate() {
            let ready_at = match entry.state {
                State::Waiting { ready_at } if ready_at <= now => ready_at,
                _ => continue,
            };
            if !entry
                .dependencies
                .iter()
                .all(|&d| matches!(self.entries[d].state, State::Succeeded))
            {
                continue;
            }

            let effective = if self.aging_ms == 0 {
                entry.job.priority
            } else {
                let gained = (now - ready_at) / self.aging_ms;
                (u64::from(entry.job.priority) + gained).min(9) as u8
            };
            if best.map_or(true, |(bi, bp)| effective > bp || (effective == bp && i < bi)) {
                best = Some((i, effective));
            }
        }

        self.last_time = now;
        let Some((i, _)) = best else {
            return Ok(None);
        };
        let entry = &mut self.entries[i];
        entry.attempts += 1;
        entry.state = State::Running {
            attempt: entry.attempts,
        };
        Ok(Some(Ticket {
            id: entry.job.id.clone(),
            attempt: entry.attempts,
        }))
    }

    pub fn complete(&mut self, now: u64, id: &str, success: bool) -> Result<(), Error> {
        if now < self.last_time {
            return Err(Error::TimeReversed);
        }
        if !self.cycle_started {
            return Err(Error::NoCycle);
        }
        let Some(i) = self.entries.iter().position(|e| e.job.id == id) else {
            return Err(Error::Unknown);
        };
        if !matches!(self.entries[i].state, State::Running { .. }) {
            return Err(Error::NotRunning);
        }

        self.last_time = now;
        if success {
            self.entries[i].state = State::Succeeded;
        } else if self.entries[i].attempts == self.entries[i].job.max_attempts {
            self.entries[i].state = State::Failed;
            self.propagate_blocked();
        } else {
            let attempt = self.entries[i].attempts;
            let mut delay = self.retry_base;
            for _ in 1..attempt {
                delay = delay.saturating_mul(2).min(self.retry_cap);
            }
            delay = delay.min(self.retry_cap);
            self.entries[i].state = State::Waiting {
                ready_at: now.saturating_add(delay),
            };
        }
        Ok(())
    }

    pub fn status(&self, id: &str) -> Result<State, Error> {
        if !self.cycle_started {
            return Err(Error::NoCycle);
        }
        self.entries
            .iter()
            .find(|e| e.job.id == id)
            .map(|e| e.state.clone())
            .ok_or(Error::Unknown)
    }

    fn propagate_blocked(&mut self) {
        loop {
            let to_block: Vec<usize> = self
                .entries
                .iter()
                .enumerate()
                .filter_map(|(i, e)| {
                    if !matches!(e.state, State::Waiting { .. }) {
                        return None;
                    }
                    e.dependencies
                        .iter()
                        .any(|&d| matches!(self.entries[d].state, State::Failed | State::Blocked))
                        .then_some(i)
                })
                .collect();
            if to_block.is_empty() {
                break;
            }
            for i in to_block {
                self.entries[i].state = State::Blocked;
            }
        }
    }
}

impl Runner {
    pub fn new(
        jobs: Vec<Job>,
        aging_ms: u64,
        retry_base: u64,
        retry_cap: u64,
    ) -> Result<Self, Error> {
        if retry_base == 0 || retry_cap < retry_base {
            return Err(Error::Config);
        }

        use std::collections::{HashMap, HashSet};

        let mut ids = HashMap::new();
        for (i, job) in jobs.iter().enumerate() {
            if job.id.is_empty()
                || job.id.len() > 16
                || !job
                    .id
                    .bytes()
                    .all(|b| b.is_ascii_lowercase() || b.is_ascii_digit() || b == b'-')
            {
                return Err(Error::BadId(i));
            }
            if job.priority > 9 {
                return Err(Error::BadPriority(i));
            }
            if job.max_attempts == 0 || job.max_attempts > 32 {
                return Err(Error::BadAttempts(i));
            }
            if ids.contains_key(&job.id) {
                return Err(Error::Duplicate(i));
            }
            ids.insert(job.id.clone(), i);
        }

        let mut dependencies = Vec::with_capacity(jobs.len());
        for (i, job) in jobs.iter().enumerate() {
            let mut seen = HashSet::new();
            let mut resolved = Vec::with_capacity(job.dependencies.len());
            for (j, name) in job.dependencies.iter().enumerate() {
                if !seen.insert(name.as_str()) {
                    return Err(Error::DuplicateDependency(i, j));
                }
                match ids.get(name) {
                    Some(&dep) => resolved.push(dep),
                    None => return Err(Error::MissingDependency(i, j)),
                }
            }
            dependencies.push(resolved);
        }

        fn visit(node: usize, deps: &[Vec<usize>], marks: &mut [u8]) -> bool {
            if marks[node] == 1 {
                return false;
            }
            if marks[node] == 2 {
                return true;
            }
            marks[node] = 1;
            for &dep in &deps[node] {
                if !visit(dep, deps, marks) {
                    return false;
                }
            }
            marks[node] = 2;
            true
        }

        let mut marks = vec![0; jobs.len()];
        for i in 0..jobs.len() {
            if !visit(i, &dependencies, &mut marks) {
                return Err(Error::Cycle);
            }
        }

        let entries = jobs
            .into_iter()
            .zip(dependencies)
            .map(|(job, dependencies)| Entry {
                job,
                dependencies,
                state: State::Waiting { ready_at: 0 },
                attempts: 0,
            })
            .collect();

        Ok(Self {
            entries,
            aging_ms,
            retry_base,
            retry_cap,
            last_time: 0,
            cycle_started: false,
        })
    }

            return Err(Error::TimeReversed);

    pub fn next_ready(&mut self, now: u64) -> Result<Option<Ticket>, Error> {
        if now < self.last_time {
            return Err(Error::TimeReversed);
        }
        if !self.cycle_started {
            return Err(Error::NoCycle);
        }

        let mut best: Option<(usize, u8)> = None;
        for (i, entry) in self.entries.iter().enumerate() {
            let ready_at = match entry.state {
                State::Waiting { ready_at } if ready_at <= now => ready_at,
                _ => continue,
            };
            if !entry.dependencies.iter().all(|&dep| {
                matches!(self.entries[dep].state, State::Succeeded)
            }) {
                continue;
            }

            let priority = if self.aging_ms == 0 {
                entry.job.priority
            } else {
                let age = (now - ready_at) / self.aging_ms;
                (entry.job.priority as u64 + age).min(9) as u8
            };

            if best.is_none_or(|(best_i, best_priority)| {
                priority > best_priority || (priority == best_priority && i < best_i)
            }) {
                best = Some((i, priority));
            }
        }

        self.last_time = now;
        let Some((i, _)) = best else {
            return Ok(None);
        };

        let entry = &mut self.entries[i];
        entry.attempts += 1;
        entry.state = State::Running {
            attempt: entry.attempts,
        };
        Ok(Some(Ticket {
            id: entry.job.id.clone(),
            attempt: entry.attempts,
        }))
    }

    pub fn complete(&mut self, now: u64, id: &str, success: bool) -> Result<(), Error> {
        if now < self.last_time {
            return Err(Error::TimeReversed);
        }
        if !self.cycle_started {
            return Err(Error::NoCycle);
        }
        let Some(i) = self.entries.iter().position(|entry| entry.job.id == id) else {
            return Err(Error::Unknown);
        };
        if !matches!(self.entries[i].state, State::Running { .. }) {
            return Err(Error::NotRunning);
        }

        self.last_time = now;
        if success {
            self.entries[i].state = State::Succeeded;
        } else if self.entries[i].attempts == self.entries[i].job.max_attempts {
            self.entries[i].state = State::Failed;
            self.propagate_blocked();
        } else {
            let attempt = self.entries[i].attempts;
            let delay = self.retry_delay(attempt);
            self.entries[i].state = State::Waiting {
                ready_at: now.saturating_add(delay),
            };
        }
        Ok(())
    }

    pub fn status(&self, id: &str) -> Result<State, Error> {
        if !self.cycle_started {
            return Err(Error::NoCycle);
        }
        self.entries
            .iter()
            .find(|entry| entry.job.id == id)
            .map(|entry| entry.state.clone())
            .ok_or(Error::Unknown)

    fn retry_delay(&self, attempt: u8) -> u64 {
        let mut delay = self.retry_base;
        for _ in 1..attempt {
            if delay >= self.retry_cap.saturating_add(1) / 2 {
                return self.retry_cap;
            }
            delay *= 2;
        }
        delay.min(self.retry_cap)
    }

    pub fn new(

        retry_base: u64,
        retry_cap: u64,

            return Err(Error::Config);
        }

        use std::collections::{HashMap, HashSet};

        let mut ids = HashMap::new();

            if job.id.is_empty()
                || job.id.len() > 16
                || !job
                    .id
                    .bytes()
                    .all(|b| b.is_ascii_lowercase() || b.is_ascii_digit() || b == b'-')

                return Err(Error::BadId(i));
            }

                return Err(Error::BadPriority(i));
            }

                return Err(Error::BadAttempts(i));
            }
            if ids.insert(job.id.as_str(), i).is_some() {
                return Err(Error::Duplicate(i));
            }
        }

        let mut dependencies = Vec::with_capacity(jobs.len());
        for (i, job) in jobs.iter().enumerate() {
            let mut seen = HashSet::new();
            let mut resolved = Vec::with_capacity(job.dependencies.len());
            for (j, dep) in job.dependencies.iter().enumerate() {

                    return Err(Error::DuplicateDependency(i, j));
                }
                match ids.get(dep.as_str()) {
                    Some(&index) => resolved.push(index),
                    None => return Err(Error::MissingDependency(i, j)),
                }
            }
            dependencies.push(resolved);
        }

        let mut colors = vec![0u8; jobs.len()];
        fn visit(node: usize, dependencies: &[Vec<usize>], colors: &mut [u8]) -> bool {
            if colors[node] == 1 {
                return false;
            }
            if colors[node] == 2 {
                return true;
            }
            colors[node] = 1;
            for &dep in &dependencies[node] {
                if !visit(dep, dependencies, colors) {
                    return false;
                }
            }
            colors[node] = 2;
            true
        }
        for i in 0..jobs.len() {
            if !visit(i, &dependencies, &mut colors) {
                return Err(Error::Cycle);
            }
        }

        let entries = jobs
            .into_iter()
            .enumerate()
            .map(|(i, job)| Entry {
                job,
                dependencies: dependencies[i].clone(),
                state: State::Waiting { ready_at: 0 },
                attempts: 0,
            })
            .collect();

        Ok(Self {
            entries,
            aging_ms,
            retry_base,
            retry_cap,
            last_time: 0,
            cycle_started: false,
        })
    }

    fn check_time(&self, now: u64) -> Result<(), Error> {
        if now < self.last_time {
            Err(Error::TimeReversed)
        } else {
            Ok(())
        }
    }

    fn find(&self, id: &str) -> Result<usize, Error> {
        self.entries
            .iter()
            .position(|entry| entry.job.id == id)
            .ok_or(Error::Unknown)
    }

        self.check_time(now)?;
        if self.cycle_started
            && self.entries.iter().any(|entry| {
                matches!(entry.state, State::Waiting { .. } | State::Running { .. })
            })
        {
            return Err(Error::Busy);
        }

        for entry in &mut self.entries {
            entry.state = State::Waiting { ready_at: now };
            entry.attempts = 0;
        }
        self.cycle_started = true;
        self.last_time = now;
        Ok(())
    }

    pub fn next_ready(&mut self, now: u64) -> Result<Option<Ticket>, Error> {
        self.check_time(now)?;
        if !self.cycle_started {
            return Err(Error::NoCycle);
        }

        let mut best: Option<(usize, u8)> = None;
        for (i, entry) in self.entries.iter().enumerate() {
            let ready_at = match entry.state {
                State::Waiting { ready_at } if ready_at <= now => ready_at,
                _ => continue,
            };
            if !entry
                .dependencies
                .iter()
                .all(|&dep| matches!(self.entries[dep].state, State::Succeeded))
            {
                continue;
            }
            let effective = if self.aging_ms == 0 {
                entry.job.priority
            } else {
                let gained = (now - ready_at) / self.aging_ms;
                (entry.job.priority as u64 + gained).min(9) as u8
            };
            if best.map_or(true, |(_, priority)| effective > priority) {
                best = Some((i, effective));
            }
        }

        self.last_time = now;
        if let Some((i, _)) = best {
            let entry = &mut self.entries[i];
            entry.attempts += 1;
            let attempt = entry.attempts;
            entry.state = State::Running { attempt };
            Ok(Some(Ticket {
                id: entry.job.id.clone(),
                attempt,
            }))
        } else {
            Ok(None)
        }
    }

    pub fn complete(&mut self, now: u64, id: &str, success: bool) -> Result<(), Error> {
        self.check_time(now)?;
        if !self.cycle_started {
            return Err(Error::NoCycle);
        }
        let index = self.find(id)?;
        if !matches!(self.entries[index].state, State::Running { .. }) {
            return Err(Error::NotRunning);
        }

        if success {
            self.entries[index].state = State::Succeeded;
        } else if self.entries[index].attempts == self.entries[index].job.max_attempts {
            self.entries[index].state = State::Failed;
            self.propagate_blocked();
        } else {
            let attempt = self.entries[index].attempts;
            let mut delay = self.retry_base;
            for _ in 1..attempt {
                delay = delay.saturating_mul(2).min(self.retry_cap);
            }
            delay = delay.min(self.retry_cap);
            self.entries[index].state = State::Waiting {
                ready_at: now.saturating_add(delay),
            };
        }

        self.last_time = now;
        Ok(())
    }

            let mut newly_blocked = Vec::new();

                if matches!(entry.state, State::Waiting { .. })
                    && entry.dependencies.iter().any(|&dep| {
                        matches!(
                            self.entries[dep].state,
                            State::Failed | State::Blocked
                        )
                    })
                {
                    newly_blocked.push(i);
                }
            }
            if newly_blocked.is_empty() {
                break;
            }
            for i in newly_blocked {
                self.entries[i].state = State::Blocked;
            }
        }
    }

    pub fn status(&self, id: &str) -> Result<State, Error> {
        if !self.cycle_started {
            return Err(Error::NoCycle);
        }
        let index = self.find(id)?;
        Ok(self.entries[index].state.clone())
    }

            }
            if !(1..=32).contains(&j.max_attempts) {
                return Err(Error::BadAttempts(i));
            }
            if index.insert(j.id.as_str(), i).is_some() {
                return Err(Error::Duplicate(i));
            }
        }

        let mut edges = vec![Vec::new(); jobs.len()];
        for (i, j) in jobs.iter().enumerate() {
            let mut seen = std::collections::HashSet::new();
            for (k, name) in j.dependencies.iter().enumerate() {
                if !seen.insert(name.as_str()) {
                    return Err(Error::DuplicateDependency(i, k));
                }
                let Some(&dep) = index.get(name.as_str()) else {
                    return Err(Error::MissingDependency(i, k));
                };
                edges[i].push(dep);
            }
        }

        fn detect(i: usize, edges: &[Vec<usize>], color: &mut [u8]) -> bool {
            match color[i] {
                1 => return true,
                2 => return false,
                _ => {}
            }
            color[i] = 1;
            for &d in &edges[i] {
                if detect(d, edges, color) {
                    return true;
                }
            }
            color[i] = 2;
            false
        }

        let mut color = vec![0; jobs.len()];
        for i in 0..jobs.len() {
            if detect(i, &edges, &mut color) {
                return Err(Error::Cycle);
            }
        }

        let n = jobs.len();
        Ok(Self {
            jobs,
            states: vec![State::Waiting { ready_at: 0 }; n],
            attempts: vec![0; n],
            aging_ms,
            retry_base,
            retry_cap,
            last_time: 0,
            active: false,
            edges,
        })

        if now < self.last_time {
            return Err(Error::TimeReversed);

        if self.active
            && self.states.iter().any(|s| matches!(s, State::Waiting { .. } | State::Running { .. }))

            return Err(Error::Busy);

        self.active = true;
        self.last_time = now;

    pub fn next_ready(&mut self, now: u64) -> Result<Option<Ticket>, Error> {

            return Err(Error::TimeReversed);
        }
        if !self.active {
            return Err(Error::NoCycle);
        }
        let mut chosen: Option<(usize, u8)> = None;
        for i in 0..self.jobs.len() {
            let State::Waiting { ready_at } = self.states[i] else { continue };
            if ready_at > now || self.edges[i].iter().any(|&d| self.states[d] != State::Succeeded) {
                continue;
            }
            let p = if self.aging_ms == 0 {

                ((self.jobs[i].priority as u64 + (now - ready_at) / self.aging_ms).min(9)) as u8
            };
            if chosen.map_or(true, |(j, q)| p > q || (p == q && i < j)) {
                chosen = Some((i, p));
            }
        }
        self.last_time = now;
        if let Some((i, _)) = chosen {
            self.attempts[i] += 1;
            self.states[i] = State::Running { attempt: self.attempts[i] };
            Ok(Some(Ticket { id: self.jobs[i].id.clone(), attempt: self.attempts[i] }))
        } else {
            Ok(None)
        }
    }

    pub fn complete(&mut self, now: u64, id: &str, success: bool) -> Result<(), Error> {
        if now < self.last_time {
            return Err(Error::TimeReversed);
        }
        if !self.active {
            return Err(Error::NoCycle);
        }
        let Some(i) = self.jobs.iter().position(|j| j.id == id) else { return Err(Error::Unknown) };
        if !matches!(self.states[i], State::Running { .. }) {
            return Err(Error::NotRunning);
        }

        self.last_time = now;
        if success {
            self.states[i] = State::Succeeded;
        } else if self.attempts[i] == self.jobs[i].max_attempts {
            self.states[i] = State::Failed;
            loop {
                let mut changed = false;
                for j in 0..self.jobs.len() {
                    if matches!(self.states[j], State::Waiting { .. })
                        && self.edges[j].iter().any(|&d| matches!(self.states[d], State::Failed | State::Blocked))
                    {
                        self.states[j] = State::Blocked;
                        changed = true;
                    }
                }
                if !changed { break; }
            }
        } else {
            let mut delay = self.retry_base;
            for _ in 1..self.attempts[i] {
                delay = delay.saturating_mul(2).min(self.retry_cap);
            }
            delay = delay.min(self.retry_cap);
            self.states[i] = State::Waiting { ready_at: now.saturating_add(delay) };
        }
        Ok(())
    }

        self.jobs.iter().position(|j| j.id == id).map(|i| self.states[i].clone()).ok_or(Error::Unknown)
    }

    retry_cap: u64,

    pub fn new(
        jobs: Vec<Job>,
        aging_ms: u64,
        retry_base: u64,
        retry_cap: u64,
    ) -> Result<Self, Error> {
        use std::collections::{HashMap, HashSet, VecDeque};

        if retry_base == 0 || retry_cap < retry_base {
            return Err(Error::Config);
        }
        let mut id_to_index = HashMap::new();
        for (i, job) in jobs.iter().enumerate() {
            let valid = (1..=16).contains(&job.id.len())
                && job
                    .id
                    .bytes()
                    .all(|b| b.is_ascii_lowercase() || b.is_ascii_digit() || b == b'-');
            if !valid {
                return Err(Error::BadId(i));
            }
            if job.priority > 9 {
                return Err(Error::BadPriority(i));
            }
            if !(1..=32).contains(&job.max_attempts) {
                return Err(Error::BadAttempts(i));
            }
            if id_to_index.insert(job.id.clone(), i).is_some() {
                return Err(Error::Duplicate(i));
            }
        }

        let mut dependencies = vec![Vec::new(); jobs.len()];
        let mut indegree = vec![0usize; jobs.len()];
        let mut dependents = vec![Vec::new(); jobs.len()];
        for (i, job) in jobs.iter().enumerate() {
            let mut seen = HashSet::new();
            for (j, dep) in job.dependencies.iter().enumerate() {
                if !seen.insert(dep) {
                    return Err(Error::DuplicateDependency(i, j));
                }
                let &dep_index = id_to_index
                    .get(dep)
                    .ok_or(Error::MissingDependency(i, j))?;
                dependencies[i].push(dep_index);
                indegree[i] += 1;
                dependents[dep_index].push(i);
            }
        }

        let mut queue = VecDeque::new();
        for (i, &degree) in indegree.iter().enumerate() {
            if degree == 0 {
                queue.push_back(i);
            }
        }
        let mut processed = 0;
        while let Some(node) = queue.pop_front() {
            processed += 1;
            for &child in &dependents[node] {
                indegree[child] -= 1;
                if indegree[child] == 0 {
                    queue.push_back(child);
                }
            }
        }
        if processed != jobs.len() {
            return Err(Error::Cycle);
        }

        let entries = jobs
            .into_iter()
            .enumerate()
            .map(|(i, job)| Entry {
                job,
                dependencies: dependencies[i].clone(),
                state: State::Waiting { ready_at: 0 },
                attempts: 0,
            })
            .collect();

        Ok(Self {
            entries,
            id_to_index,
            aging_ms,
            retry_base,
            retry_cap,
            last_time: 0,
            cycle_started: false,
        })

        } else {

            entry.attempts = 0;

        self.cycle_started = true;
        self.last_time = now;

        if !self.cycle_started {

        }

        for i in 0..self.entries.len() {

            let ready_at = match entry.state {

                _ => continue,
            };
            if entry
                .dependencies

                .any(|&d| !matches!(self.entries[d].state, State::Succeeded))
            {
                continue;
            }
            let effective = if self.aging_ms == 0 {
                entry.job.priority
            } else {
                let aged = u64::from(entry.job.priority)
                    .saturating_add((now - ready_at) / self.aging_ms)
                    .min(9) as u8;
                aged
            };
            if chosen.is_none() || effective > chosen_priority {
                chosen = Some(i);
                chosen_priority = effective;
            }
        }

        self.last_time = now;
        if let Some(i) = chosen {
            let entry = &mut self.entries[i];
            entry.attempts += 1;
            let attempt = entry.attempts;
            entry.state = State::Running { attempt };
            Ok(Some(Ticket {

                attempt,
            }))
        } else {
            Ok(None)
        }

        if !self.cycle_started {
            return Err(Error::NoCycle);

                } else {

        Ok(self.entries[i].state.clone())
