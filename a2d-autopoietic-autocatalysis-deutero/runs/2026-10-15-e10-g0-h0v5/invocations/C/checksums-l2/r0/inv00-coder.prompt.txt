## requirements

Implement the following cumulative checksum contract.

R1. Implement in Rust as a SINGLE source file that compiles with rustc --edition 2024, std only. Output ONLY the Rust source code inside ```rust fences. Do not use inner attributes (#![...]) or inner doc comments (//!).

R2. All API items below are pub. Span, Hashes and all error enums must implement Debug, Clone, Copy, PartialEq, Eq. Define pub struct Span { pub start: usize, pub end: usize }, pub struct Hashes { pub crc32: u32, pub adler32: u32 }, and pub enum SpanError { Reversed { span: usize }, OutOfBounds { span: usize, offset: usize }, Overlap { span: usize } }. Indices in errors are zero based.

R3. Provide pub fn crc32(data: &[u8]) -> u32. CRC-32 is reflected IEEE: initialize the internal register to 0xffffffff, xor each byte into its low bits, perform eight right shifts per byte, xoring 0xedb88320 after each shift whose old low bit was 1, then xor the final register with 0xffffffff.

R4. CRC-32 of an empty slice is 0. Every byte including zero and bytes >=128 is processed as an unsigned byte; there is no text decoding or terminator.

R5. Provide pub fn adler32(data: &[u8]) -> u32. Start a=1,b=0; for each byte x set a=(a+x)%65521 and then b=(b+a)%65521. Return (b<<16)|a.

R6. Adler-32 of an empty slice is 1. Reductions must be mathematically exact even for long slices; machine integer overflow must not change the result.

R7. Provide pub fn checksums(data: &[u8]) -> Hashes, returning exactly the results of crc32 and adler32 on that slice. All checksum outputs are numeric integers, independent of host byte order.

R8. Provide pub fn checksums_spans(data: &[u8], spans: &[Span]) -> Result<Hashes, SpanError>. A span selects data[start..end], with end exclusive. Successful results hash the concatenation of the selected bytes in supplied order, excluding gaps, with a single initialization for the entire concatenation.

R9. Validate spans in supplied order. The first failing span wins, regardless of which error categories occur in later spans. Do not sort or coalesce spans.

R10. Within each span, check start>end first and return Reversed { span: its_index }. This takes precedence even when an endpoint is out of bounds.

R11. After the reversed check, check start>data.len(), then end>data.len(). Return OutOfBounds { span: its_index, offset: the_offending_endpoint }. Endpoints equal to data.len() are valid.

R12. After endpoint checks, for every span after the first require start>=the immediately preceding span's end, otherwise return Overlap { span: its_index }. Thus bounds errors outrank overlap at the same span.

R13. Empty spans (start==end) are valid, contribute no bytes, and still participate in BOTH sides of the ordering comparison. An empty span strictly inside the preceding span is an overlap. An empty span in a gap advances the ordering boundary to its own end.

R14. Adjacent spans and repeated empty spans at the same position are valid. Spans must be ordered even when they select identical byte contents.

R15. No spans, or a valid collection containing only empty spans, yields Hashes { crc32: 0, adler32: 1 }, regardless of unselected data.

R16. All slice APIs accept arbitrary binary data. CRC and Adler accumulation crosses span boundaries without resetting either algorithm.

R17. All errors are returned as specified, never panics for malformed spans. Calls have no externally observable state and must not modify input slices.

R18. Compute in time linear in selected byte count plus span count and bounded auxiliary space; do not allocate a copy of the concatenated selected bytes.

R19. Keep every level-1 API and behavior above. Add pub struct Stream with private implementation fields; it must implement Debug and Clone. Add pub enum SnapshotError { Shape, Hex { offset: usize }, Adler { component: usize } }, implementing Debug, Clone, Copy, PartialEq, Eq.

R20. Provide pub fn new() -> Self as an associated Stream function. Its state is the standard empty CRC/Adler state. Provide pub fn checksum(&self) -> Hashes; reading the checksum does not mutate/finalize the stored state.

R21. Provide pub fn from_seed(crc32: u32, adler32: u32) -> Result<Self, SnapshotError> as an associated Stream function. The arguments are already finalized numeric checksums. Resume CRC processing from crc32 xor 0xffffffff and Adler from a=adler32&0xffff, b=adler32>>16; do not process seed bytes or add an extra initial 1.

R22. For from_seed, a and b must each be <65521. If a is invalid return Adler { component: 0 }, else if b is invalid return Adler { component: 1 }. Any u32 CRC is valid. Adler seed 0 is valid.

R23. Provide pub fn update(&mut self, data: &[u8]) on Stream. It appends bytes to the current state. Results are identical under every chunking, including empty chunks; an empty update preserves even an arbitrary valid seed exactly.

R24. Provide pub fn update_spans(&mut self, data: &[u8], spans: &[Span]) -> Result<(), SpanError>. Validate exactly as checksums_spans. The entire call is atomic: any error leaves BOTH checksum components unchanged even if earlier spans were valid. On success append selected bytes without resetting or padding at boundaries.

R25. Provide pub fn reset(&mut self) on Stream. It returns to the standard empty state, including for streams created from a seed or restored snapshot. Cloning a stream copies its state; subsequent updates to either copy are independent.

R26. Provide pub fn snapshot(&self) -> String on Stream. It returns exactly c followed by eight lowercase hexadecimal digits of the finalized CRC, then :a followed by eight lowercase hexadecimal digits of the packed Adler checksum, e.g. c00000000:a00000001. The token is exactly 19 ASCII bytes with leading zeroes and no whitespace.

R27. Provide pub fn restore(token: &str) -> Result<Self, SnapshotError> as an associated Stream function. Check shape first: byte length must be 19 and bytes 0,9,10 must be c,:,a respectively; otherwise Shape. Shape errors outrank all digit/seed errors.

R28. After shape passes, scan the digit bytes at offsets 1..9 then 11..19 in increasing byte-offset order. Only ASCII 0-9 and a-f are accepted; uppercase, whitespace, non-ASCII and all other bytes return Hex { offset: the_first_bad_byte_offset }. Validate ALL digit bytes before numeric seed validity.

R29. After digits pass, parse the two numbers and apply from_seed, including a-before-b Adler validation. Restoring a valid snapshot must resume exactly; snapshot/checksum calls never change future updates.

R30. Stream methods must be public with the exact signatures specified, and process input in time linear in the bytes/spans without retaining input copies. Snapshot/restore have constant sized state.
