R3. Paths use POSIX slash separators. All offsets are zero-based UTF-8 byte offsets in the original string supplying the offending component or character, never character indices.

R4. Validate the entire raw path before reducing any component. An empty string returns Empty.

R5. After the empty check, any NUL byte returns Nul at its first occurrence, even if an earlier backslash, control, or root escape exists.

R6. If no NUL exists, any backslash byte returns Backslash at its first occurrence, even if an earlier control or root escape exists.

R7. If neither NUL nor backslash exists, ASCII bytes 1 through 31 and 127 are forbidden: return Control at the first such byte, even if a root escape occurs earlier.

R8. All other bytes in a valid UTF-8 input are allowed literally. Do not trim whitespace, decode percent escapes, fold case, or normalize Unicode. A tilde is literal for normalize.

R9. A path is absolute exactly when its first byte is slash. Collapse every run of slashes, including two or more leading slashes, to ordinary POSIX separators; there is only one root.

R10. Process nonempty components left to right. Discard components equal to dot (.). Dots inside any other name are ordinary characters.

R11. A parent component (..) removes the previous ordinary component, if one exists. It must never cancel a preceding retained parent component.

R12. For an absolute path, a parent with no component to remove returns Escape at the first byte of that parent. The earliest such event in traversal order wins.

R13. For a relative path, a parent with no ordinary component to remove is retained. Leading retained parents may grow without limit.

R14. Join components with single slashes and prefix one slash only for an absolute path. An empty absolute result is /; an empty relative result is dot (.).

R15. Directory intent is true when the raw path ends in slash OR its last nonempty component is dot or parent. Otherwise it is false.

R16. Append a single trailing slash to a nonempty component result exactly when directory intent is true. Never append to root / or the empty-relative result dot. In particular, normalize("..") is "../", normalize("a/..") is ".", and normalize("a/.") is "a/".

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum PathError {
    Empty,
    Nul { at: usize },
    Backslash { at: usize },
    Control { at: usize },
    Escape { at: usize },
}

pub fn normalize(path: &str) -> Result<String, PathError> {
    if path.is_empty() {
        return Err(PathError::Empty);
    }

    if let Some(at) = path.as_bytes().iter().position(|&b| b == 0) {
        return Err(PathError::Nul { at });
    }

    if let Some(at) = path.as_bytes().iter().position(|&b| b == b'\\') {
        return Err(PathError::Backslash { at });
    }

    if let Some(at) = path
        .as_bytes()
        .iter()
        .position(|&b| (1..=31).contains(&b) || b == 127)
    {
        return Err(PathError::Control { at });
    }

    let absolute = path.as_bytes()[0] == b'/';
    let directory_intent = path.ends_with('/')
        || path
            .split('/')
            .filter(|component| !component.is_empty())
            .last()
            .is_some_and(|component| component == "." || component == "..");

    let mut components: Vec<&str> = Vec::new();
    let mut offset = 0;

    for component in path.split('/') {
        let component_at = offset;
        offset += component.len() + 1;

        if component.is_empty() || component == "." {
            continue;
        }

        if component == ".." {
            if components.last().is_some_and(|last| *last != "..") {
                components.pop();
            } else if absolute {
                return Err(PathError::Escape { at: component_at });
            } else {
                components.push(component);
            }
        } else {
            components.push(component);
        }
    }

    let mut result = String::new();
    if absolute {
        result.push('/');
    }
    result.push_str(&components.join("/"));

    if result.is_empty() {
        result.push('.');
    }

    if directory_intent && result != "/" && result != "." {
        result.push('/');
    }

    Ok(result)
}

fn main() {}
