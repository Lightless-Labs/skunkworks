The bug is that the DP keeps one “best” suffix per `(word, offset, first-line)` state, but the tie-break rules compare complete consumed-count vectors and complete rendered lines; choosing a suffix locally can discard the globally winning layout. Use a DAG shortest-path DP that stores the best *complete path* under the full ordered objective (cost, marker lines, line count, consumed vector, then pre-justification lines), or encode that objective in a comparable path score. For justification, retain piece boundaries as path data and render only after the winning path is selected.
