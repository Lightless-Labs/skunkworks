R3. Encoding uses six-bit digits, most significant bits first, with the alphabet ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/. Decode accepts bytes, not text; offsets are zero-based physical byte indices in the original encoded input.

R4. Each three input bytes encode to four digits. A one-byte tail emits two digits and ==; a two-byte tail emits three digits and =. Encoded tail bits are zero; there is no newline. Empty input encodes to an empty string and decodes to an empty Vec.

R5. Decode processes input left to right in groups of four non-skipped bytes. Four alphabet digits emit three bytes; xx== emits one byte; xxx= emits two bytes. x means an alphabet digit. Padding may appear only in the final group.

R6. At group positions zero or one, = immediately produces BadPadding at that byte. At position two, = is held pending until the next non-skipped byte or EOF.

R7. After a pending position-two =, any next non-skipped byte other than = produces BadPadding at that next byte, even if that byte would otherwise be invalid.

R8. An = at position three completes a valid padded group. After any completed padded group, every further non-skipped byte produces BadPadding at that byte, even an invalid byte or more =.

R9. When neither R6, R7 nor R8 applies, a byte outside the selected alphabet other than = produces InvalidByte { offset, byte }. No whitespace is skipped at this level; CR, LF, space, tab and non-ASCII bytes are invalid.

R10. At EOF a pending position-two = with no fourth byte produces BadPadding at the position-two =, not Truncated.

R11. At EOF any other nonempty incomplete group produces Truncated at the FIRST byte of that incomplete group; the offset is not the EOF index.

R12. Errors found while scanning always win over EOF errors. The earliest immediately detectable scan error wins; do not prevalidate the length or scan for invalid characters before applying the group rules.

R13. Decoding accepts nonzero unused bits in a final digit; for example Zh== decodes to f and Zm9= decodes to fo. Do not enforce canonical trailing bits at this level.

R14. On success, decoding returns precisely the reconstructed bytes, including zero and bytes >=128; encoding supports every byte value.

R15. The one-shot functions are stateless. An Err returns no partial decoded Vec, even if a valid group precedes the error.

R16. The error precedence in a single group is terminal-padding state (R8), then pending-second-padding expectation (R7), then illegal = placement (R6), then invalid byte (R9); EOF uses R10 before R11. No error is produced for valid empty input.

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Error {
    InvalidByte { offset: usize, byte: u8 },
    BadPadding { offset: usize },
    Truncated { offset: usize },
}

const ALPHABET: &[u8; 64] =
    b"ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/";

fn digit(byte: u8) -> Option<u8> {
    ALPHABET.iter().position(|&b| b == byte).map(|n| n as u8)
}

pub fn encode(input: &[u8]) -> String {
    let mut out = String::with_capacity((input.len() + 2) / 3 * 4);
    let mut chunks = input.chunks_exact(3);

    for chunk in &mut chunks {
        let n = ((chunk[0] as u32) << 16) | ((chunk[1] as u32) << 8) | chunk[2] as u32;
        out.push(ALPHABET[((n >> 18) & 63) as usize] as char);
        out.push(ALPHABET[((n >> 12) & 63) as usize] as char);
        out.push(ALPHABET[((n >> 6) & 63) as usize] as char);
        out.push(ALPHABET[(n & 63) as usize] as char);
    }

    match chunks.remainder() {
        [a] => {
            out.push(ALPHABET[(a >> 2) as usize] as char);
            out.push(ALPHABET[((a & 3) << 4) as usize] as char);
            out.push_str("==");
        }
        [a, b] => {
            out.push(ALPHABET[(a >> 2) as usize] as char);
            out.push(ALPHABET[(((a & 3) << 4) | (b >> 4)) as usize] as char);
            out.push(ALPHABET[((b & 15) << 2) as usize] as char);
            out.push('=');
        }
        _ => {}
    }

    out
}

pub fn decode(input: &[u8]) -> Result<Vec<u8>, Error> {
    let mut output = Vec::new();
    let mut group: Vec<(u8, usize)> = Vec::with_capacity(4);
    let mut pending_padding: Option<usize> = None;
    let mut padded_group_complete = false;

    for (offset, &byte) in input.iter().enumerate() {
        if padded_group_complete {
            return Err(Error::BadPadding { offset });
        }

        if let Some(padding_offset) = pending_padding {
            if byte != b'=' {
                return Err(Error::BadPadding { offset });
            }
            pending_padding = None;
            padded_group_complete = true;

            let a = digit(group[0].0).unwrap();
            let b = digit(group[1].0).unwrap();
            output.push((a << 2) | (b >> 4));
            group.clear();
            let _ = padding_offset;
            continue;
        }

        let position = group.len();
        if byte == b'=' {
            match position {
                0 | 1 => return Err(Error::BadPadding { offset }),
                2 => pending_padding = Some(offset),
                3 => {
                    let a = digit(group[0].0).unwrap();
                    let b = digit(group[1].0).unwrap();
                    let c = digit(group[2].0).unwrap();
                    output.push((a << 2) | (b >> 4));
                    output.push((b << 4) | (c >> 2));
                    group.clear();
                    padded_group_complete = true;
                }
                _ => unreachable!(),
            }
            if position == 2 {
                group.push((byte, offset));
            }
            continue;
        }

        let value = digit(byte).ok_or(Error::InvalidByte { offset, byte })?;
        group.push((byte, offset));

        if group.len() == 4 {
            let a = digit(group[0].0).unwrap();
            let b = digit(group[1].0).unwrap();
            let c = digit(group[2].0).unwrap();
            let d = value;
            output.push((a << 2) | (b >> 4));
            output.push((b << 4) | (c >> 2));
            output.push((c << 6) | d);
            group.clear();
        }
    }

    if let Some(offset) = pending_padding {
        return Err(Error::BadPadding { offset });
    }

    if !group.is_empty() {
        return Err(Error::Truncated {
            offset: group[0].1,
        });
    }

    Ok(output)
}
