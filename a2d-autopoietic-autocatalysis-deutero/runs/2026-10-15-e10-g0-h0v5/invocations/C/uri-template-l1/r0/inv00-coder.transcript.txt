R1. Implement in Rust as a SINGLE source file that compiles with rustc --edition 2024, std only. Output ONLY the Rust source code inside ```rust fences. All API items below must be pub; derive Debug, Clone, PartialEq, Eq for Error. No inner attributes or inner documentation comments.

Additional private helpers are allowed. Do not require a main function.

R3. Expansion returns the concatenation of literal spans and brace expressions. Preserve literal text byte for byte, including Unicode, percent signs, spaces, and newlines. Empty template returns an empty string.

R4. Every pos is a zero-based UTF-8 byte offset into template. Error variants use exactly the fields in R2. No errors are reported for unused bindings or binding names.

R5. Validate the entire template syntax before looking up or expanding any binding. Scan expressions and literal characters left to right; the first syntax error encountered wins. A later syntax error takes precedence over any earlier value error.

R6. Outside expressions, an unmatched '}' is UnexpectedClose at that brace. An opening '{' starts an expression; locate the first following '}'. If none exists, return Unclosed at the opening brace (even if more '{' occur later).

R7. When a closing brace exists, any '{' between this expression's braces causes NestedOpen at the first such inner brace, before checking anything else inside that expression. There are no brace escapes.

R8. At the beginning of expression content, recognize at most one operator from + # . / ; ? &. Supported operators at this level are none. A recognized but unsupported operator causes UnsupportedOperator at its byte; other punctuation is handled as an invalid name. With no operator use simple expansion.

R9. After removing an operator, empty content causes EmptyExpression at the closing brace. Otherwise split content on commas into variable specifiers, preserving empty entries. An empty entry causes EmptyVariable at its start (the closing brace for a trailing empty entry).

R10. A variable name must match ASCII [A-Za-z_][A-Za-z0-9_]*. Names are case sensitive. InvalidName points to the first offending byte, including the first byte of any non-ASCII character. Whitespace is never trimmed. Modifiers are not supported: a colon or asterisk is an invalid name byte.

R11. Validate specifiers left to right. For each, validate its name, then reject a name already used in this expression with DuplicateVariable at this specifier start. The same name may appear in different expressions. Operator checks precede all specifier checks.

R12. Look up a name by exact equality in vars. If bindings repeat a name, the LAST binding wins, including an empty value. Binding names themselves are not validated. An absent variable contributes no field and no separator.

R13. Encode values by their UTF-8 bytes: ASCII letters, digits, hyphen, period, underscore, tilde pass unchanged. Every other byte becomes %HH with uppercase hexadecimal digits, subject to the percent-triplet rule.

R14. An existing percent sign followed by two ASCII hexadecimal digits forms a triplet: preserve it but uppercase both hex digits, consume all three bytes, and do not decode it. This applies even to %41 and %25. An invalid or incomplete triplet encodes the percent as %25 and processes the remaining bytes normally. Triplets are recognized greedily from left to right.

R15. Simple expansion joins the fields of present variables with commas and has no expression prefix. A present empty scalar contributes one empty field, so adjacent present variables can create leading, internal, or trailing commas. An expression with no contributed fields produces no output.

R16. Every malformed template returns the specified Err without panicking. Inputs are not mutated and calls have no shared state. A syntactically valid template with arbitrary scalar binding strings always succeeds.

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Error {
    UnexpectedClose { pos: usize },
    Unclosed { pos: usize },
    NestedOpen { pos: usize },
    EmptyExpression { pos: usize },
    UnsupportedOperator { pos: usize },
    EmptyVariable { pos: usize },
    InvalidName { pos: usize },
    DuplicateVariable { pos: usize },
}

fn is_name_start(byte: u8) -> bool {
    byte.is_ascii_alphabetic() || byte == b'_'
}

fn is_name_continue(byte: u8) -> bool {
    is_name_start(byte) || byte.is_ascii_digit()
}

fn is_operator(byte: u8) -> bool {
    matches!(byte, b'+' | b'#' | b'.' | b'/' | b';' | b'?' | b'&')
}

fn is_supported_operator(byte: u8) -> bool {
    false
}

fn is_hex(byte: u8) -> bool {
    byte.is_ascii_hexdigit()
}

fn encode_value(value: &str) -> String {
    let bytes = value.as_bytes();
    let mut output = String::new();
    let mut i = 0;

    while i < bytes.len() {
        let byte = bytes[i];

        if byte == b'%' && i + 2 < bytes.len() && is_hex(bytes[i + 1]) && is_hex(bytes[i + 2]) {
            output.push('%');
            output.push((bytes[i + 1] as char).to_ascii_uppercase());
            output.push((bytes[i + 2] as char).to_ascii_uppercase());
            i += 3;
        } else if byte.is_ascii_alphanumeric() || matches!(byte, b'-' | b'.' | b'_' | b'~') {
            output.push(byte as char);
            i += 1;
        } else {
            output.push('%');
            output.push_str(&format!("{:02X}", byte));
            i += 1;
        }
    }

    output
}

fn validate_expression(
    content: &str,
    content_start: usize,
    closing: usize,
) -> Result<Vec<(String, usize)>, Error> {
    let bytes = content.as_bytes();
    let mut start = 0;

    if !bytes.is_empty() && is_operator(bytes[0]) {
        if !is_supported_operator(bytes[0]) {
            return Err(Error::UnsupportedOperator { pos: content_start });
        }
        start = 1;
    }

    if start == bytes.len() {
        return Err(Error::EmptyExpression { pos: closing });
    }

    let mut names: Vec<(String, usize)> = Vec::new();
    let mut spec_start = start;

    for i in start..=bytes.len() {
        if i == bytes.len() || bytes[i] == b',' {
            if spec_start == i {
                return Err(Error::EmptyVariable {
                    pos: content_start + spec_start,
                });
            }

            let spec = &bytes[spec_start..i];
            if !is_name_start(spec[0]) {
                return Err(Error::InvalidName {
                    pos: content_start + spec_start,
                });
            }

            for (offset, byte) in spec.iter().enumerate().skip(1) {
                if !is_name_continue(*byte) {
                    return Err(Error::InvalidName {
                        pos: content_start + spec_start + offset,
                    });
                }
            }

            let name = String::from_utf8(spec.to_vec()).unwrap();
            if names.iter().any(|(prior, _)| prior == &name) {
                return Err(Error::DuplicateVariable {
                    pos: content_start + spec_start,
                });
            }
            names.push((name, content_start + spec_start));
            spec_start = i + 1;
        }
    }

    Ok(names)
}

pub fn expand(template: &str, vars: &[(&str, &str)]) -> Result<String, Error> {
    let bytes = template.as_bytes();
    let mut output = String::new();
    let mut cursor = 0;

    while cursor < bytes.len() {
        match bytes[cursor] {
            b'}' => return Err(Error::UnexpectedClose { pos: cursor }),
            b'{' => {
                let open = cursor;
                let mut close = cursor + 1;
                while close < bytes.len() && bytes[close] != b'}' {
                    close += 1;
                }
                if close == bytes.len() {
                    return Err(Error::Unclosed { pos: open });
                }

                if let Some(inner) = (open + 1..close).find(|&i| bytes[i] == b'{') {
                    return Err(Error::NestedOpen { pos: inner });
                }

                let content_start = open + 1;
                let content = &template[content_start..close];
                let names = validate_expression(content, content_start, close)?;

                let mut fields = Vec::new();
                for (name, _) in names {
                    if let Some((_, value)) = vars.iter().rev().find(|(key, _)| *key == name) {
                        fields.push(encode_value(value));
                    }
                }
                output.push_str(&fields.join(","));
                cursor = close + 1;
            }
            _ => {
                let next = template[cursor..].chars().next().unwrap();
                output.push(next);
                cursor += next.len_utf8();
            }
        }
    }

    Ok(output)
}
