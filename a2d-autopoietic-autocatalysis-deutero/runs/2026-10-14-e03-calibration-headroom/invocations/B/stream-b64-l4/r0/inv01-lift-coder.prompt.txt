Encoding: encode arbitrary bytes using consecutive 6-bit groups, most significant bits first. The Standard alphabet in index order is ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/. Unused bits in the final sextet are zero. Empty input encodes to the empty string. Decoding returns arbitrary bytes, not necessarily UTF-8.
UrlSafe uses the same first 62 symbols, then '-' and '_' instead of '+' and '/'. Accept only the selected alphabet; never accept a symbol exclusive to the other alphabet. Padding::Required produces '=' padding to a multiple of four characters and requires it for a final partial group. Padding::Forbidden emits no '=' and rejects every '=' on input. Full groups need no '=' in either mode. Forbidden mode allows a final group of two or three alphabet symbols, producing one or two bytes; a final single symbol is InvalidLength. Every padded or unpadded final partial group must be canonical: the low four bits of the second sextet in a one-byte group, or the low two bits of the third sextet in a two-byte group, must be zero. Otherwise return NonCanonical at the raw byte offset of that sextet. Check this only when the padded quartet is complete, or at finish/EOF for an unpadded tail; earlier structural or character errors take precedence.
When ignore_whitespace is true, skip exactly ASCII space (0x20), horizontal tab (0x09), LF (0x0a), vertical tab (0x0b), form feed (0x0c), and CR (0x0d), anywhere, including between padding characters and after terminal padding. No other whitespace is ignored. When false, those bytes are processed normally and are invalid alphabet bytes unless a higher-priority rule below applies. Empty or entirely ignored input succeeds with no bytes. Offsets are zero-based byte positions in the original UTF-8 input, including ignored whitespace. Streaming offsets are cumulative across all pushes; they never reset per chunk. Non-ASCII input is examined byte by byte, so an InvalidByte points to the first offending UTF-8 byte. EOF is the total raw input byte length, including trailing ignored whitespace.

Process input bytes from left to right, skipping permitted whitespace first. Apply these rules in the stated order to the remaining bytes:
1. Once a complete padded quartet has been accepted, any further byte is TrailingData. Even an otherwise invalid character or an extra '=' takes this error.
2. '=' is InvalidPadding at quartet positions 0 or 1 (positions are zero-based); it is also always InvalidPadding in Forbidden mode. At position 2 it begins '=='; at position 3 it completes either 'xxx=' or 'xx=='.
3. After '=' at position 2, the next nonignored byte must be '='. Any other byte, even a byte outside the alphabet, is InvalidPadding.
4. Otherwise a byte outside the selected alphabet is InvalidByte.
For these byte-triggered errors the offset is the byte that violates the rule, not an earlier padding byte.
A complete valid quartet yields its decoded bytes immediately. Padding ends the data, so it cannot occur in an interior quartet. At EOF, any incomplete quartet in Required mode, or a single leftover symbol in Forbidden mode, is InvalidLength with offset equal to EOF. This includes an incomplete 'xx=' group: it is InvalidLength, not InvalidPadding. Validation follows byte order: an encountered error is reported before EOF length validation. One-shot decode returns Err without any partial result on error.

Streaming: new starts empty and open. Encoder::push emits every newly completed triple of bytes as four symbols and retains only the remaining zero, one, or two bytes. It emits no padding. Encoder::finish emits the retained tail using the configured encoding rules (possibly an empty string). Decoder::push emits every newly completed quartet, including a completed padded quartet, and retains any incomplete group. It does not perform EOF validation. In Forbidden mode two or three leftover symbols produce no bytes until finish. Decoder::finish validates EOF and emits any legal final tail (empty for Required padding). Concatenating all successful push outputs and the finish output equals one-shot output, for any chunk boundaries, including empty chunks. There is no UTF-8 restriction on decoded bytes.
A successful finish seals its stream. Any later push (including an empty push) or finish returns Finished. A padded Decoder remains open until finish, allowing subsequent ignored whitespace when enabled; further data instead produces the error above. A decoding error from push or finish is sticky: that exact error, including its original offset, is returned by every later push or finish. Sticky errors take precedence over Finished. If push errors, it returns no output for that call even if earlier quartets in that same call decoded successfully; earlier successful calls' returned output is unaffected. Encoder operations on an open stream never error. There are no required panic cases.

fn public_options(alphabet: Alphabet, padding: Padding, ignore_whitespace: bool) -> Options {
    Options { alphabet, padding, ignore_whitespace }
}

#[test]
fn public_configured_one_shot() {
    let standard = public_options(Alphabet::Standard, Padding::Required, false);
    assert_eq!(encode(b"f", standard), "Zg==");
    assert_eq!(decode("Zg==", standard), Ok(b"f".to_vec()));
    let url = public_options(Alphabet::UrlSafe, Padding::Forbidden, false);
    assert_eq!(encode(&[251, 255], url), "-_8");
    assert_eq!(decode("-_8", url), Ok(vec![251, 255]));
}

#[test]
fn public_canonical_error() {
    let o = public_options(Alphabet::Standard, Padding::Required, false);
    assert_eq!(decode("Zh==", o), Err(DecodeError::NonCanonical { offset: 1 }));
    assert_eq!(decode("?AAA", o), Err(DecodeError::InvalidByte { offset: 0 }));
}

#[test]
fn public_configured_encoder() {
    let mut e = Encoder::new(public_options(Alphabet::UrlSafe, Padding::Forbidden, false));
    assert_eq!(e.push(&[251]), Ok("".into()));
    assert_eq!(e.push(&[255]), Ok("".into()));
    assert_eq!(e.finish(), Ok("-_8".into()));
    assert_eq!(e.finish(), Err(StreamError::Finished));
}

#[test]
fn public_configured_decoder() {
    let mut d = Decoder::new(public_options(Alphabet::UrlSafe, Padding::Forbidden, true));
    assert_eq!(d.push(" -"), Ok(vec![]));
    assert_eq!(d.push("_8\n"), Ok(vec![]));
    assert_eq!(d.finish(), Ok(vec![251, 255]));
    assert_eq!(d.push(""), Err(DecodeError::Finished));
}
