Encoding: encode arbitrary bytes using consecutive 6-bit groups, most significant bits first. The Standard alphabet in index order is ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/. Unused bits in the final sextet are zero. Empty input encodes to the empty string. Decoding returns arbitrary bytes, not necessarily UTF-8.
Always produce '=' padding to a multiple of four characters. A final one-byte group uses two alphabet symbols followed by '=='; a two-byte group uses three symbols followed by '='. Decoding requires complete four-symbol groups, including this padding. Do NOT reject non-zero unused bits in a padded final group: e.g. 'Zh==' decodes to b'f' and 'Zm9=' decodes to b'fo'.
No whitespace is ignored. All non-alphabet bytes other than legal '=' padding are rejected, including whitespace and non-ASCII UTF-8 bytes. Empty input succeeds with no bytes.

Process input bytes from left to right, skipping permitted whitespace first. Apply these rules in the stated order to the remaining bytes:
1. Once a complete padded quartet has been accepted, any further byte is InvalidPadding. Even an otherwise invalid character or an extra '=' takes this error.
2. '=' is InvalidPadding at quartet positions 0 or 1 (positions are zero-based); At position 2 it begins '=='; at position 3 it completes either 'xxx=' or 'xx=='.
3. After '=' at position 2, the next nonignored byte must be '='. Any other byte, even a byte outside the alphabet, is InvalidPadding.
4. Otherwise a byte outside the selected alphabet is InvalidByte.
A complete valid quartet yields its decoded bytes immediately. Padding ends the data, so it cannot occur in an interior quartet. At EOF, any incomplete quartet is InvalidLength. This includes an incomplete 'xx=' group: it is InvalidLength, not InvalidPadding. Validation follows byte order: an encountered error is reported before EOF length validation. One-shot decode returns Err without any partial result on error.

Streaming: new starts empty and open. Encoder::push emits every newly completed triple of bytes as four symbols and retains only the remaining zero, one, or two bytes. It emits no padding. Encoder::finish emits the retained tail using the configured encoding rules (possibly an empty string). Decoder::push emits every newly completed quartet, including a completed padded quartet, and retains any incomplete group. It does not perform EOF validation. Decoder::finish validates EOF and emits any legal final tail (empty for Required padding). Concatenating all successful push outputs and the finish output equals one-shot output, for any chunk boundaries, including empty chunks. There is no UTF-8 restriction on decoded bytes.
A successful finish seals its stream. Any later push (including an empty push) or finish returns Finished. A padded Decoder remains open until finish, allowing subsequent ignored whitespace when enabled; further data instead produces the error above. A decoding error from push or finish is sticky: that exact error, including its original offset, is returned by every later push or finish. Sticky errors take precedence over Finished. If push errors, it returns no output for that call even if earlier quartets in that same call decoded successfully; earlier successful calls' returned output is unaffected. fn alphabet_value(byte: u8) -> Option<u8> {
    match byte {
        b'A'..=b'Z' => Some(byte - b'A'),
        b'a'..=b'z' => Some(byte - b'a' + 26),
        b'0'..=b'9' => Some(byte - b'0' + 52),
        b'+' => Some(62),
        b'/' => Some(63),
        _ => None,
    }
}

fn encode_triple(a: u8, b: u8, c: u8, output: &mut String) {
    const ALPHABET: &[u8; 64] =
        b"ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/";

    output.push(ALPHABET[(a >> 2) as usize] as char);
    output.push(ALPHABET[(((a & 0x03) << 4) | (b >> 4)) as usize] as char);
    output.push(ALPHABET[(((b & 0x0f) << 2) | (c >> 6)) as usize] as char);
    output.push(ALPHABET[(c & 0x3f) as usize] as char);
}

            return Err(error);

            return Err(DecodeError::Finished);

                Some(DecodeError::InvalidPadding)

                && self.quartet[2] == b'='

                    self.quartet_len += 1;
                    if self.quartet_len == 4 {

            return Err(DecodeError::InvalidLength);
        }

        self.finished = true;
        Ok(Vec::new())
    }
}

        Self::new()
    }
