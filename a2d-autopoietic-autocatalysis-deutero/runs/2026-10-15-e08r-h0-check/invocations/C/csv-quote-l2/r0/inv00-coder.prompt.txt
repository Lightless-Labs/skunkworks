Reject returns DuplicateHeader for the earliest second occurrence scanning header columns left to right: name is the repeated value, first is its earliest column, and second is the current column, both zero-based. KeepFirst and KeepLast preserve the full header vector and all row cells, including duplicate columns.\n\nR26. When a header exists, every data record must have exactly the header width. The first data record of wrong width returns HeaderWidth with record equal to its zero-based input record index (thus first data record is 1), expected=header length, actual=row length. No padding or truncation occurs.\n\nR27. Error precedence for read_csv/finish is invalid Config, then the first lexical error anywhere in input, then duplicate-header validation, then the first width mismatch. DuplicatePolicy only changes duplicate-header validation, not this order.\n\nR28. Table::column_index returns None with no header or no exact name match. With KeepLast, return the greatest matching column; with KeepFirst or Reject, return the least. This also applies to manually constructed Tables, even ones with duplicate names under Reject. This lookup never validates row widths.\n\nR29. read_csv is equivalent to new(config), feed(input), finish().
