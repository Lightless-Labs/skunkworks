- Field splitting is on literal spaces only, with empty pieces retained; lexical validation scans the whole field before item parsing.
- Item structure is checked before numeric values; numeric endpoints are validated in order before range reversal and step checks.
- Only an exact `*` marks a day field unrestricted; full-domain restricted day sets print as `*/1`.
- When both day fields are restricted, ordinary dates use OR, while the month’s actual last day uses AND.
- Window bounds are validated before ordering and cap checks; the interval is half-open and `truncated` requires finding one extra fire.
- Search iterates dates and selected times rather than every minute, so sparse schedules remain practical across the full supported range.

  Ok(FireWindow{fires,truncated:false})
 }

 }
